# Аудит интерфейса после RC11 — 11.10.2026

Проверяется рабочая версия после PR #43 приложения и PR #9 паков. Публикация RC11 не изменяется. Это отчёт о конечной проверяемой матрице, а не утверждение о любом существующем устройстве.

## Найдено и исправлено

| Проблема | Причина и итог |
| --- | --- |
| Третья карточка соперника обрезалась на 320 px | Три карточки попадали в две строки под ограничителем высоты. Теперь они помещаются одной строкой; имя, тип/очки и статус используют компактную сетку. |
| Поле сдвигалось при смене хода | Дополнительный статус переносил строки. Для статуса зарезервировано одинаковое место, остальные элементы сохраняют позиции. |
| Вертикальная прокрутка мини-рук | Высоты и min-height из паков конфликтовали с общей областью. Общий размер миниатюр теперь задаёт приложение. |
| Закрытая рука обрезалась по горизонтали | В горизонтальной карточке ширина информации и руки зависела от содержимого; несколько правил имели больший приоритет. Области явно делят ширину, пересчёт учитывает изменение реальной области участников/руки. |
| Публичный Стол оставлял пустую колонку и лишние подсказки | Личные actions/hand попадали в автоматические строки сетки. На публичной поверхности они исключены; поле получает оставшуюся ширину. Последний кубик передаётся в публичный status. |
| Костяшки цепочки домино выходили за края и меняли пропорции | Минимальная ширина превышала колонку. Горизонтальные кости и дубли используют постоянные пропорции и помещаются в колонку. |
| Поле карт выглядело мелким на ПК/планшете | Подгонка только уменьшала компоненты. При достаточном месте поле теперь увеличивается до 1.4, сохраняя пропорции. |
| Повторные подсказки Дурака | Убраны пояснения выбора карты под полем; доступны игровые подсказки самих объектов и правила. |
| Меню игрока повторным нажатием на руку открывалось заново | Обработчик внешнего нажатия не считал всю карточку частью цели. Информация и рука одинаково переключают меню. |
| В настройках главного меню были правила невыбранной игры | Кнопка показывается только в контексте комнаты/игры. Основные настройки компактны, объяснения и прослушивание свёрнуты. |
| История отдавала место декоративным рубашкам и отдельному заголовку | Закрытые руки представлены счётчиком в карточке, открытые руки сохранены. Счётчик хода находится рядом с управлением повтором; недоступные действия скрыты. |
| Сетевой экран повторял имена и режим над карточками | В списке связи остаются только отключённые участники; при общей связи строка скрыта. Дублирующий подзаголовок убран, состояние Стола/рук остаётся в статусе. |
| У гостя в слоте Стола не было удаления | Хост видит корзину у занятого гостем Стола. |

## Проверяемая матрица

- Все пять игр: UNO, Дурак, Домино, Шашки, Змеи и лестницы.
- Телефоны: 320×640, 390×740; короткие landscape 640×280 и 740×390. Для настоящих действий дополнительно 568×320, 740×360, 844×390, 932×430, 960×540.
- Планшеты: 768×1024, 1024×768; ПК: 1280×900, 1920×1080. Сохранены 13 дополнительных размеров из присланных скриншотов.
- Живая игра/история, закрытые/открытые руки, публичный Стол; реальные комнаты хоста и клиента всех паков с поворотом/изменением размера.
- Главная, библиотека партий, справка, настройки, паки и комната на 320/390/740/768/1024/1440 px.
- Действия мышью и touch, выбор/drag карт и шашек, длинные руки, карта выбора цвета, UNO-меню, передача телефона, готовность/пауза, роли и места, возврат из правил, удаление/продолжение/история партии, ошибки паков и приватность.
- Измеряются переполнения, границы областей, пропорции, размеры основных кнопок, положение кнопок и поля, отсутствие обрезки рук и дублирующей оболочки.

## Проверки и границы результата

Используются существующие сценарии и блоки тестов; расширены варианты размеров и состояний, новый отдельный проверочный фреймворк не создан. После найденных дефектов повторяются связанные сценарии. Последняя целевая проверка компоновки, истории и домино: 182/182, без пропусков/отмен. Полный совместный прогон `bash scripts/codex/check.sh --full --app-dir ../playroom` из репозитория паков: 662/662. После последней правки сетевых подписей повторён `bash scripts/codex/check.sh --full --packs-dir ../playroom-paks/packs` из приложения: **662/662**, exit 0, fail/cancelled/skipped 0. Блоки: core 65, input 79, games 278, UI 123, storage 31, network 49, pairing/PWA 37.

Снимки получены в локальном Chromium с реальными рендерами приложения и WebRTC-сценариями. Физические Android/iOS, безопасные отступы конкретных экранов, камера/микрофон и обновление установленной PWA на устройстве требуют живой приёмки. Известные ограничения ICE/LAN и условия стабильного выпуска остаются в прежнем плане приёмки; этот аудит их не закрывает.

На предельно коротком экране 640×280 в истории длинная цепочка и списки игроков могут требовать прокрутки внутри своей области: сохранена читаемость, страница и соседние области не прокручиваются вместе. Эта резервная компоновка не равна обещанию уместить любое число карт/костяшек без прокрутки.
