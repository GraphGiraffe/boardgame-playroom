# RC18: постоянная компоновка и общие цели хода

Приложение 0.18.0-rc.18, коллекция 0.7.0-rc.14, канал 0.18-rc.14. Только preview, стабильная production не меняется.

- Приложение закрепляет сетку партии и собственную зону. Изменение размера окна, новая партия и явное действие с allowLayoutChange разрешают новый расчёт. Флага на весь пак нет.
- Лишние инструкции ожидания/выбора удалены из игровых действий; важные названия доступны на кнопках и в правилах.
- Общие boardTarget/routeDot используются в Лудо и ЗиЛ+. Цветная интерактивная цель сохраняет белую иконку спецклетки.
- Спецклетки и бейджи согласованы по цветам; начало змеи/лестницы исключено на них. Стартовая фишка не уменьшается от невидимых соседей.
- В тесной руке выделенная карта сохраняет доступ к соседним картам; наведение не передвигает цели нажатия. Панель UNO не скрывается из-за пустой группы, завершение партии не добавляет лишний ряд кнопок в заголовке.
- Восемь цветов мест: зелёный, красный, синий, жёлтый, оранжевый, фиолетовый, голубой, серый.

Проверки: core,input,case/rc2-presentation-browser,case/network-feedback-browser,case/rc2-games,case/pack-models. Геометрия всех 12 игр проверяется между выбором/действиями на 320×640, 390×844, 640×320 и 844×390; снимки tmp_files/rc2-presentation/rc18-all-*.png. Итог основного прогона: 343/343, без пропусков (app 0eb273d, packs f7bd675). После него отдельно проверяется исправление слоёв поля: клетки и цели ниже змей/лестниц, фишки выше всех. Публикация фиксируется после завершения.

Поправка ЗиЛ+ выбирается одной парой кнопок −1/+1 до хода и может переключаться: цели обоих кубиков пересчитываются, но поправка применяется только к выбранному. Автоматический второй кубик остаётся без поправки. Иконки спецклеток занимают 64% стороны; ±1 использует system-ui 800, как счётчики.
