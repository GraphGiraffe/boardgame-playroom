# Пасьянсы и наследование скинов

Область применения: приложение **0.21.0** и коллекция **0.8.9**, engineApi 4 / viewApi 3 / protocol 3. Исторические этапы ниже поясняют совместимость; текущая приёмка хранится в [utils](https://github.com/GraphGiraffe/boardgame-playroom-utils/blob/main/docs/project/app/reports/ACCEPTANCE-0.21.0.md).

Косынка и Паук входят в коллекцию 0.8.9; точные версии перечислены в манифестах паков. Исследования Windows XP остаются историческим обоснованием; этот документ описывает действующее поведение ХОД.

## Игры

Косынка: 52 карты, семь столбцов 1…7, 24 карты в запасе. Добор 1/3; доступна верхняя карта сброса. Чередование цветов при переносах, король в пустой столбец, дома A…K одной масти; разрешён возврат из дома. Ручное/автоматическое открытие, лимит 1/3/∞ полных проходов, обычный счёт/без счёта/Vegas. Vegas задаёт 1 проход при доборе 1 и 3 при доборе 3; баланс −52, +5 за карту в доме, −5 за возврат. Автосбор по двойному нажатию на пустое поле включён по умолчанию: последовательно переносит доступные открытые карты в дома, не раздавая запас. Опция позволяет отключить жест. Один сбор — одно действие и одна отмена.

Паук: 104 уникальных экземпляра, 1/2/4 масти; 4×6 + 6×5 карт на поле, 50 в запасе. Перенос группы — только открытая убывающая одномастная последовательность; цель любой масти старше на один ранг. Пустой столбец принимает любую допустимую группу. Автоматические открытие и снятие K…A; победа после восьми серий. Добор сразу по одной карте в десять столбцов; при пустом столбце запрещён по умолчанию, есть облегчённая опция.

Отмена: выкл / последнее / история до 100 действий. Revision и счётчик действий продолжают расти. В Пауке режим «Последнее» не проходит через раздачу или снятие серии; «История» может их отменять. Штраф отмены ХОД: 1 очко в Пауке, 2 в Косынке. Обычный счёт Паука: начало 500, −1 за действие, +100 за серию, минимум 0. В Косынке обычный счёт: +5 за сброс→столбец/открытие, +10 за дом, −15 за возврат; переворот при доборе 1 −100, при доборе 3 после третьего прохода −20, минимум 0.

Точное воспроизведение XP не заявляется: временные штрафы/бонус, накопительный Vegas и заводские флажки XP не реализованы. Подготовительные таблицы этих вариантов не являются обещанием реализованных настроек.

## Экран и ввод

Один человек, без ботов, руки, панели игрока, очередности и передачи устройства. Обычные действия имеют `turnEnded:false`; timeline остаётся в одном ходе. Редактор не показывает «Игрок №1»/«Порядок»; SDK создаёт одного человека по умолчанию у моделей maxPlayers=1. Сетевая комната не предлагает solo-паки.

Локальная итерация компоновки по проверке на телефоне: стандартный скин по умолчанию, семь увеличенных столбцов Косынки; у Паука карты от 40px с локальной горизонтальной прокруткой в портрете, все десять столбцов на полной ширине landscape. Соло-поле не резервирует боковые зоны игроков. Общие кнопки действий находятся снизу по центру. Шаг открытых стандартных карт — 35% высоты вместо 72%; мини-скин остаётся доступен и сохраняет больший шаг для крупного номинала. Длинные стопки прокручиваются внутри поля.

Переносы, раздача и отмена применяются сразу через существующую `quietActions`-политику. Соло-карты используют opt-in `data-drag-start="immediate"`: начало по движению от 3px без таймера удержания; короткое касание остаётся выбором. Общий input переносит всю размеченную группу `data-drag-stack`/`data-drag-stack-member` с исходными размерами и смещением пальца; не создаёт отдельный полёт из отсутствующей руки. Другие игры сохраняют прежнюю политику жестов.

Подсказки локальны, не меняют revision/RNG/счёт. Выделяется только источник/цель конкретного переноса либо запас/карта открытия. Повторный вызов перебирает доступные рекомендации. Кнопка очистки, Escape, ручной выбор, игровое действие, пауза и история убирают рамки. Подсказки не восстанавливаются из navigation state после reload. Отсутствие рекомендации не объявляет расклад проигранным и не доказывает его неразрешимость.

## Скины

Новый отдельный asset pack `mini-split-deck@0.1.0`, вариант `card-face:mini-split`: номинал в верхней половине, масть в нижней, пропорции 5:7. Старые лица и mini-cards сохранены. Специальный Web recipe лица не заменяется скином; рубашки относятся к отдельному семейству.

Из главного меню доступны только темы, без скинов и образцов компонентов паков. В партии кнопка тем в настройках открывает «Темы и скины» текущего пака. Показываются только его skinFamilies с более чем одним доступным вариантом; при отсутствии выбора блок скинов не создаётся. Например, сейчас у Косынки и Паука доступны четыре стиля лиц карт, а рубашка с единственным вариантом скрыта. В UNO, Шашках и Домино блок скинов пока отсутствует.

Сохранённые общие и индивидуальные предпочтения `playroom.skins.v1` сохраняются совместимыми. Выбор сначала показывается в черновике; Сохранить записывает его на устройстве, Отмена/Escape/закрытие восстанавливают принятые значения. Образцы используют уже загруженный игровой renderer; отдельные копии ресурсов паков для главного меню не нужны.

Метаданные пака: `skinFamilies` перечисляет применимые семейства, `defaultSkins` задаёт исходные варианты. Неизвестный установленному каталогу скин безопасно отображается стандартным без удаления сохранённого выбора. Manifest прежних паков с новыми метаданными получает новую packVersion; опубликованные файлы не заменяются.

## Проверка

Адресные сценарии: `case/solitaire`, `case/skin-preferences`, `case/solitaire-browser`; сопутствующие проверки `case/appearance`, `case/appearance-browser`, `case/game-screen`, `case/views`, `case/view-contract`. Артефакты и снимки — `BoardGames/tmp_files/solitaire-implementation/`; сборки — `BoardGames/tmp_files/solitaire-build/`. Первый адресный прогон: 74/74; дополнительный перенос tap/drag: 1/1. Полный тестовый цикл не запускался; широкая проверка engine остановлена и заменена проверкой SDK одного игрока внутри case/solitaire. Проверка правил/браузера не означает точную совместимость XP или физическую приёмку на всех устройствах.

Локальная проверка следующей компоновки: `case/solitaire-browser`, `case/solitaire-input`, `case/drag`. Release/Actions/deploy не запускаются. Новые исходные версии 0.1.1 не переписывают локальные 0.1.0; для просмотра новой компоновки запустить новую партию.

Телефонная итерация v2: адресные браузерные проверки экранов (2), нового touch-drag (2) и прежнего общего ввода (21 с учётом вложенных сценариев runner — суммарно 25 в выбранных блоках). Никаких широких симуляций правил соседних игр. Скриншоты и локальная сборка: `BoardGames/tmp_files/solitaire-layout-v2/`.

Запас и сброс используют общие card-back/countBadge, очки и действия — общий counter/score renderer (с сохранением отрицательного счёта Vegas). Пустые дома показывают крупные масти; визуальный порядок ♥/♣/♦/♠ сопоставляется с исходными индексами домов, правила и сохранения не меняются. В landscape верхние строки освобождают поле: счётчики слева, короткое сообщение/подсказка справа от нижних кнопок. Кнопки с общими SVG-иконками имеют aria-label и всплывающую справку. Последние адресные экраны и touch-перенос: 4/4.

Дополнение локальной итерации: «Серии» перенесены вправо от нижних кнопок в обеих ориентациях, сообщение в landscape занимает строку под ними. Пустой сброс использует общий card-back, как в «Акулине»; после добора остаётся видимая выдача одной/трёх карт. Боковые поля и постоянный резерв scrollbar уменьшены в пользу ширины карт.

Итерация v3 по видеозаписи: серый слот пустого сброса, лицевые карты после добора; светло-зелёное поле, общий пропорциональный радиус карт и слотов. Отключён hand-preview с поднятием одной карты над хвостом. opt-in immediate начинает drag непосредственно на pointerdown; проекция dragSources включает переносимые группы даже без допустимой цели (отпускание возвращает их без команды). Проверка настоящего renderer поднимает три карты одним касанием и переносит всю группу; перед измерением drop-цели тест ждёт два кадра завершения переразметки. Общая политика удержания других игр не меняется. Справка XP: https://documentation.help/Solitaire/sol9k6x.htm .

Локальный артефакт v3: версии паков и solitaire-board 0.1.2, чтобы не подменять точные 0.1.1 из предыдущего HTML. Запуск новой партии использует новые версии. Финальные выбранные проверки: 39/39; release/Actions/deploy не запускались.

Отмена immediate drag: отпускание вне цели после движения и pointercancel/Escape сбрасывают локальный выбор, ghost и затемнение всей группы без игровой команды. Постоянный серый selected-фильтр удалён; краткий tap по-прежнему позволяет выбрать источник для последующего нажатия на цель.

## История локальной итерации v4

Паки/поле 0.1.3 сохраняют отдельные точные версии прежних локальных сборок. В Пауке запас — компактная кнопка с числом раздач; в landscape общие счётчики и управление находятся в середине заголовка, без отдельного нижнего ряда. В портрете управление снизу. Дома Косынки идут ♥/♣/♦/♠; общий приём всей зоны направляет карту в допустимый дом своей масти. Подсказка называет карту и масть, отсекает симметричные перемещения и немедленный обратный ход; это ограниченная эвристика прогресса, не доказательство выигрышности расклада.

Автосбор запускается двойным кликом/тапом именно по пустому полю; двойное нажатие по карте его не вызывает. Domain выдаёт только публичную последовательность реально перенесённых карт. Общая motion-система анимирует её по порядку, учитывает отключение анимации и отмену/resize; durable state уже применён атомарно. Для запаса предусмотрен переворот и раздача, для сброса — сдвиги оставшихся карт. История анимирует ручные шаги и воспроизведение; отмена drag очищает временное затемнение. Завершение мгновенным ходом также показывает общий результат, после окончания анимации.

Новые адресные сценарии: отмена группы/touchcancel; двойной тап/клик, последовательность автосбора и его отмена; неверный дом как место отпускания; история и окно победы через приложение; полезные подсказки; десять карт из компактного запаса Паука. Артефакт — `tmp_files/solitaire-layout-v4/playroom-solitaire-v4.html`. Release/Actions/deploy не запускались.

Локальная v5: рамки подсказок не сопоставляют отсутствующие ID закрытых карт; flip выделяет только открытую для действия вершину нужного столбца, draw — только запас. При доборе прежний видимый сброс сдвигается в левую часть стопки под новым веером; последняя рубашка запаса остаётся видимой до завершения переноса.

Локальная v6: итоговый score берётся из domain, отображается в стандартном счётчике очков; cleared остаётся отдельной метрикой карт/серий. Отрицательные значения показываются текстовой итоговой метрикой без обнуления, режим scoring:none не выводит очки.

Локальная v7: три кнопки действий — отмена, подсказка, добор со счётчиком; крестик убран. Кнопка добора исполняет только доступный draw/recycle, а при недоступности отключена. Косынка сохраняет также прямое нажатие запаса на поле. Escape по-прежнему снимает подсказку.

Локальная v8: ширина карт Косынки в landscape ограничена короткой стороной viewport с учётом внешних полей; поворот телефона не растягивает семь столбцов на всю длинную сторону. Размер Паука не изменён.

Локальная v9: data-scene-status=portrait переносит счётчики в статус-бар хоста, в landscape возвращает блок в скрытый слот поля, сохраняя счётчики заголовка. Подсказка оформлена общим player-status-badge.

Локальная v10: mini-split-deck 0.1.1 использует пропорциональную обычной колоде рамку 3/100 ширины и скругление около 13%, с общим материалом card-rim.

Локальная v11: classic-four-color / mini-split-four-color — дополнительные пользовательские скины; синие трефы и оранжевые бубны, прежние червы/пики. Двухцветные исходные скины и правила чередования сохраняются. Выбор поддерживает общий и индивидуальный scope с прежним Save/Cancel.

Локальная v12: текст активной подсказки — неинтерактивный popup у кнопки с aria-describedby; не занимает строку поля, скрывается при снятии подсказки/действии. В portrait над кнопкой, в landscape под кнопкой.


Локальная v15: подсказки Паука исключают перенос хвоста между равнозначными одномастными родителями. Сохраняются завершение K–A, увеличение одномастной цепочки, открытие закрытой карты и освобождение столбца; ручные легальные действия не ограничены.

Локальная v16 заменяет глобальные образцы скинов редактором только текущей партии; стили внутреннего арта домино остаются в паке.

Локальная v18: блок скинов раскрыт всегда и не имеет сброса. Подписи «4 цвета», создание копии, отдельное применение и пояснение о стандартной теме удалены. Выбор темы/скинов сначала предпросматривается, общая нижняя кнопка сохраняет; Отмена/закрытие отменяет черновик. Ранее сохранённые пользовательские темы по-прежнему доступны, редактируются и удаляются в главном редакторе.

Локальная v19: обложки принадлежат пакам (`assets/covers/*-v1.svg`), общий fitCovers задаёт тот же масштаб каталога, что у остальных игр. Паук — король бубен и мультяшный паук; Косынка — три столбца tableau без веера. Из настроек убран лишний переход «Настроить новую партию».

Локальная v21: compact-index / compact-index-four-color добавлены к сохранённым четырём скинам. Номинал и масть расположены рядом; шаг открытых карт 24% высоты, закрытых — 5px. Для новых партий пасьянсов исходный скин compact-index; явный пользовательский выбор сохраняет приоритет. Сброс Косынки у компактного скина вертикальный; остальные скины сохраняют горизонтальный веер. Два ряда выбора — двухцветные, затем четырёхцветные.
