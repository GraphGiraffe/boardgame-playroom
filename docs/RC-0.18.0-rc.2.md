## Дополнительные подтверждённые причины

1. CSS provenance был записан как JS-комментарий `//`, из-за чего браузер пропускал первый CSS-блок бабла. Сборщик пишет валидный CSS-комментарий `/* ... */`; проверяется вычисленный position и привязка к карточке.
2. Общий `.scene[aria-busy=true]{pointer-events:none}` блокировал реакции, просмотр полей и прокрутку независимо от доступных команд. Легальность/блокировки остаются в контроллере ввода; просмотр не запрещён из-за чужого хода.
3. Звук приходил раньше события: теперь принадлежит элементу очереди, проигрывается при его начале, без дублирования ACK/restore.
4. Перерисовка пересоздавала бабл и могла повторять мигание. Активный бабл сохраняется по event ID, меняется только позиция. Transient подсветки сохраняются при DOM patch.
5. Ручное `viewState={}` не очищало сохранённый объект GameScreenController. Очищаются оба, поэтому auto действительно возобновляется.
6. Пексесо было ограничено 70 px на больших экранах: поле теперь масштабируется с доступным местом до 150 px на карту.

7. PackManager терял `options.reveal` при staging/apply/rollback: локальные паки не могли показать крупный ход. Регистрация теперь сохраняет весь контракт reveal; проверены реальные локальные полёты и +4.

## Контракты

- `snapshot.independentActions` — подмножество уже разрешённых authority действий для role=player, подтверждённых `reactionControl.independent`; у history/spectator/Table пусто. Это UI-подсказка, authority по-прежнему проверяет episode, revision, command ID и приватность.
- `data-interaction-shape="circle|cell"` задаёт геометрию рамки. Доступность/выбор принадлежат общему UI, правила не читают DOM.
- Feedback принимает `mode`, исходный motion snapshot и callback движения; звук, речь, reveal и motion связываются с публичными событиями. Скрытые руки никогда не становятся источником лиц карт для анимации.
- Слои временного показа вынесены из геометрии сцены. Поля и руки сохраняют собственную необходимую прокрутку.

| Время, мс | Быстро / instant | Средне | Медленно |
|---|---:|---:|---:|
| Пропуск | 250 | 450 | 700 |
| Рассмотрение крупного хода | 450 | 750 | 1100 |
| Короткая речь | 900 | 1200 | 1600 |
| Переворот | 180 / 0 | 280 | 400 |
| Рассмотрение несовпавшей пары | 450 | 700 | 1000 |

Reduced motion убирает движение, сохраняя читаемость публичного события. Отмена очищает копии и возвращает видимость назначения.
