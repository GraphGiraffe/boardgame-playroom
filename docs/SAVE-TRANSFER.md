# Перенос сохранений · ХОД

Область применения: приложение **0.21.0** и коллекция **0.9.0**, engineApi 4 / viewApi 3 / protocol 3. Исторические этапы ниже поясняют совместимость; текущая приёмка хранится в [utils](https://github.com/GraphGiraffe/boardgame-playroom-utils/blob/main/docs/project/app/reports/ACCEPTANCE-0.21.0.md).

Локальная предварительная сборка. В «Мои партии»:

- **Экспорт** (иконка поделиться у удаления) → «Сохранить файл». Получится `.playroom-save.json` с состоянием, историей и точной версией пака.
- На другом устройстве **Импорт** (иконка сохранения над списком) → выбрать файл → «Добавить копию».
- Копия добавляется отдельно. Исходная и текущая партии не заменяются. Повторный импорт создаёт ещё одну независимую копию.

Локальные партии и архивы хоста продолжаются как локальные партии. Несколько людей играют с передачей устройства. Временный бот не превращает человека в постоянного бота: подмена, отсутствие и роль хоста не переносятся. Постоянные боты сохраняются.

Архив участника содержит только уже полученные им кадры и импортируется как история для просмотра. Недостающие кадры не восстанавливаются из воздуха; продолжить по такой истории полную партию нельзя. Сетевые роли, приглашения, пароли, ключи входа и resume-секреты в файл не переносятся. Для переноса действующего сетевого хоста используйте [передачу хоста](HOST-TRANSFER.md).

Файл содержит карты и планы, доступные владельцу сохранения. Восстановление исходной онлайн-комнаты или прав на аккаунт через него не выполняется.

## Совместимость и ошибки

- Вложенный пак устанавливается с точной версией; установленная новая версия не подставляется вместо старой.
- Другие байты пака под тем же номером версии отклоняются. Исходные партии остаются на месте.
- Старые файлы `playroom-session` поддерживаются при установленной точной версии пака. Если её нет, установите её в менеджере паков и повторите импорт.
- Формат, контрольная сумма, версия, состояния и история проверяются до добавления. Несовместимый движок/пак объясняет ошибку; исходный файл не изменяется.
- Максимальный размер файла — 48 МБ. Это дополнительно к ограничениям декодера сохранений и паков.
- Импорт не разрешён во время открытой комнаты. Закройте её и повторите.

## Устройство реализации

`application/save-transfer.js` создаёт и проверяет контейнер, SHA256 и зависимость, очищает опции от сетевого окружения. Используются существующие `Session.restore/serialize` и точные паки, новый формат игрового состояния не вводится.

`Packs.validatePrepared` временно регистрирует точные правила для синхронной проверки с восстановлением реестра; UI и хранилище при этом не меняются. Установка вложенного пака происходит после проверки. При ошибке записи копии существующие сохранения не изменяются; установленная зависимость может остаться в менеджере паков.

`Library.importAsync` добавляет новый отдельный ключ одной транзакцией IndexedDB. Импорт истории участника также атомарен, получает новые внутренние идентификаторы и не создаёт reconnect-права.

Экспорт активной партии хоста ждёт принятого durable commit, на время чтения приостанавливает приём новых команд, затем возвращает управление. Архив другого активного окна защищён Web Lock. Экспорт не закрывает комнату и не переносит authority.

Новая SQL-миграция для этого этапа не требуется. Ничего не публикуется автоматически.
