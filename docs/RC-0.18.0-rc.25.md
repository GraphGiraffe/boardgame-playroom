# RC25: разнообразные персонажи Пексесо

Приложение 0.18.0-rc.25, коллекция 0.7.0-rc.18, Пексесо 0.2.0-rc.8; новый изолированный канал 0.18-rc.18. Предыдущие релизы и preview не меняются, production остаётся 0.17.6 / 0.6.5. Все изменения RC24 включены.

Раньше Пексесо брал первые пары каталога, поэтому в лёгком режиме преобладали месяцы и треугольники. Теперь перемешиваются фигуры и палитра, набор выбирается по seed до раскладки на поле. В 8 парах — все 8 фигур и 6 цветов; для 12/18 пар фигуры повторяются равномерно в новых цветах. Пара состоит из двух идентичных изображений с разными id. Тот же seed воспроизводит весь стартовый state и rng. Игральные 36/52/54 сохраняют прежний набор пар. StateVersion 3, API и ассеты не меняются.

Проверки правки: `case/pack-models` — 18/18 и `node --test --test-name-pattern=Pexeso tests/rc2-games.test.cjs` — 6/6, без пропусков. Это валидные результаты предыдущего шага на неизменившемся коде и тестах; после пользовательского подтверждения добавлены только версия кандидата и документация, тесты повторно не запускались. Пексесо проверен на 64 seed для каждого режима, одинаковые пары, все фигуры/цвета, воспроизводимость, приватность, решения бота и завершение всех режимов. Самостоятельный `bash scripts/codex/check.sh` паков прошёл: синтаксис, сборка и 18 SHA256. Скриншоты 390×844 и 844×390 просмотрены; раскрытие всех лиц использовалось только в отдельной демонстрационной проекции, игровая приватность не меняется.

Ограничения: более широкий `case/rc2-games,case/pack-models` дал 48 pass / 1 fail из 49: прежний сценарий Лудо ожидает отсутствия data-motion-lead="roll". Та же ошибка воспроизведена на исходном RC22 d786da5ed916d083c33b38e3e90196edda443cc1. Проверка Лудо не менялась и не ослаблялась; широкий набор не считается зелёным. Подробности — PEXESO-RANDOM-REVIEW.md. Прежние ограничения общей game-layout-browser матрицы также сохраняются (RC23).

Публикация: новые immutable prereleases и архивы с exact SHA, скачанные SHA256/ZIP CRC, независимый новый каталог RC18 и один защищённый preview RC25. Workflow публикаций использует checks=none для уже проверенных файлов; protected/runtime/catalog/offline smoke обязателен. Итоговые SHA и URL фиксируются после проверки.
