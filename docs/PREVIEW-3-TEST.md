# Playroom ХОД — 0.15.0-preview.3

Дата: 2026-10-08. Это **Pre-release** для проверки браузерного мультиплеера; стабильную версию 0.13.0 он не заменяет.

## Что проверить

- Удаление последнего сохранения с недоступным паком убирает предупреждение о восстановлении.
- Подключение гостя в другой вкладке **того же профиля браузера** создаёт отдельного участника, не дублирует хоста и не занимает его место.
- Настройки комнаты показываются локализованно: название правила и текстовое значение, а не внутренний код `manual`.
- WebRTC offer/answer pairing, QR, Web Share/Share Target и `web+playroom:` открывают одну сетевую сессию без отдельного компьютера-сервера.
- Лобби: места, Ready, запуск; в UNO у игроков разные личные проекции, действия синхронизируются.
- Локальные режимы и сохранения продолжают работать. Не удаляйте данные браузера между версиями.

## Артефакты релиза

- `playroom-0.15.0-preview.3.html` — автономный HTML со всеми пятью закреплёнными играми для локального открытия.
- `playroom-0.15.0-preview.3-bundle.zip` — дополнительная поставка с HTML, PWA и README.
- `playroom-pwa-0.15.0-preview.3.zip` — статические файлы PWA для размещения **по HTTPS** (или localhost для разработки).
- `SHA256SUMS.txt` — контрольные суммы опубликованных артефактов.

Для установки PWA: распакуйте PWA ZIP на свой HTTPS-сервер, откройте его адрес в Chrome/Edge (Android, desktop) или Safari (iOS), установите приложение через меню браузера. Не открывайте PWA ZIP как отдельный `file://` — Service Worker и регистрация схемы протокола требуют secure context. Перед первым офлайн-запуском откройте приложение онлайн для установки Service Worker. QR и системная передача доступны в зависимости от браузера и ОС.

## Проверки перед выпуском

Весь набор правил, GUI и мультиплеера тестируется с пятью **закреплёнными версиями паков**, извлечёнными из проверенного CI-артефакта 11459727753 (исходный commit паков `b01652e56c70ff180f2fdde8da2f11ba115534fe`). Сборка и PWA проходят отдельные smoke-проверки **из финальных файлов**, затем для файлов релиза пересчитывается SHA-256. Физические устройства и кросс-браузерный ручной проход после публикации остаются задачей проверки.

## Ограничения

- Переход на другой браузер или устройство не переносит автоматически локальные сохранения.
- Пока нет восстановления **сетевой** партии/переподключения после закрытия вкладки и долговечного архива сетевой истории.
- Первичное подключение между устройствами требует обмена приглашением и ответом; короткий номер комнаты без signalling не работает.
- WebRTC между произвольными сетями/через NAT не гарантирован: для первой проверки предпочтительнее два устройства в одной сети.
