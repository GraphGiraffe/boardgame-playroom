# RC15 — общие окна, настройки и прокрутка рук

- Мини-справки правил используют один top-layer popover: без изменения геометрии формы, с закрытием по Escape и вне окна.
- Поля с единственным вариантом скрыты; их фиксированное значение остаётся в данных формы. Рассадка и форма руки показаны только когда применимы.
- Кнопка Темы в настройках содержит только иконку; корона владельца предшествует типу игрока.
- Уменьшены отступы главного экрана; placeholder имени — Никнейм.
- Область прокрутки руки ограничена шириной своей зоны. Размер костяшек зависит от общего размера игровых элементов, а не количества костяшек. Свайп и колесо работают для карт и домино.
- Выбор закрытой карты — модальное окно поверх экрана с крупными картами, а не обрезанная часть поля.
- Ятзи и Змеи и лестницы поддерживают 2–6 игроков; формат состояния не меняется.

Публикация только в новый preview, production не переключается. Коллекция 0.7.0-rc.11, канал 0.18-rc.11.

Каталог в landscape использует адаптивную сетку по ширине карточки, без фиксированного минимума столбцов. Исходные PNG персонажей сохранены в репозитории и source ZIP; устанавливаемый архив персонажей уменьшен с 9 296 974 до 1 329 968 байт (runtime 256×256 WebP сохранён без перекодирования). Ассет-паки characters/cartoon-deck — 0.1.1.

Локальную партию можно скрыть с главной кнопкой «Скрыть»; запись и доступ из «Моих партий» сохраняются. Скрытие сохраняется после перезагрузки и относится только к этой партии.

Проверки: case/rc2-presentation-browser, case/player-target, case/hand-navigation, case/uno-drag, case/drag-app — 61/61; дополнительный браузерный сценарий скрытия локальной партии — 1/1. Сборка приложения и проверка архивов коллекции выполнены.
