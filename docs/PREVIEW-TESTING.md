# Проверка на телефоне и ПК: экспериментальная сборка

Это тестовая ветка, не стабильный релиз. Новые локальные UNO и Дурак используют версии 0.2.0 и 0.1.1 соответственно; остальные игры — 0.1.0. Старые установленные паки и партии не перезаписывайте: для них нужна прежняя версия.

## Один экран, без сервера

Откройте `playroom-all-games.html` в браузере ПК или телефона. Внутри пять игр и обновлённое масштабирование. Сервер и установка Node не нужны. На iOS файл может открываться в просмотрщике файлов вместо Safari: для полноценной проверки обслужите его обычным HTTP-сервером на ПК.

Проверьте закрытые и открытые руки противников в UNO и Дураке, большой набор карт, смену ориентации, добор, выбор цвета, осмотр карты, локальные сохранения и историю. Миниатюра должна сохранять пропорции всей иллюстрации, рамки и символов. В UNO и Дураке есть отдельный компактный рисунок; без него используется основной. Маленькая картинка не задаёт размер зоны касания.

## Одна партия UNO: ПК + телефон в одной Wi-Fi-сети

На **ПК** нужен Node.js 22 или новее. На телефоне ничего устанавливать не нужно.

1. Распакуйте ZIP целиком. На Windows запустите `START-WINDOWS.cmd`. На macOS/Linux в папке запустите `sh START-MAC-LINUX.sh`. Скрипты запускают `node dev/serve-preview.cjs --lan`.
2. Терминал выведет ссылки «Общий стол», «Игрок 1», «Игрок 2» для локального адреса ПК. Откройте общий стол на ПК. Передайте каждому игроку **его отдельную личную ссылку** с сетевым IP, не `127.0.0.1`. Вся часть после `#key=` обязательна.
3. Откройте ссылку игрока на телефоне. Играть можно, не нажимая ничего на общем столе. На ПК можно открыть второе личное окно.
4. Перезагрузка страницы по той же ссылке сохраняет место и получает свежий снимок. При потере связи оставьте страницу открытой: опрос возобновится. Кнопка «Повторить отправку» повторяет прежнюю команду с тем же ID, а не создаёт второй ход.
5. Закрытие процесса сервера завершает тестовую партию. Следующий запуск выдаёт новую партию и новые ссылки. Сохранение LAN-партии после перезапуска пока не реализовано.

Для четырёх игроков: `node dev/serve-preview.cjs --lan --players 4`. Для двух людей и двух ботов добавьте `--bots 2`. Другой порт: `--port 4180`. Только на этом ПК: запускайте без `--lan`.

Если телефон не подключается: устройства должны видеть друг друга в локальной сети (гостевая Wi-Fi-сеть часто их разделяет), и брандмауэр ПК должен разрешать входящий TCP 4173 для **частной сети**. Не отключайте брандмауэр целиком. В терминале могут быть адреса VPN/виртуальных адаптеров: выбирайте адрес домашней сети.

Личная ссылка — ключ доступа к месту. Не публикуйте её и не отдавайте ссылку другого игрока. Это обычный HTTP без шифрования: только доверенная локальная сеть, **без доступа из интернета и без проброса портов**. Нет аккаунтов, QR, выбора места через открытый lobby или передачи роли хоста. Правила исполняет процесс Node на ПК, не вкладка общего стола.

## Что проверять

Общий стол не показывает чужие руки и не принимает команды. Личный экран показывает свою руку, колоду/сброс, цвет, направление, добор, пас, выбор цвета, ручное UNO и отдельные кнопки проверки соперника. Окно помощи одного игрока не останавливает остальных. История доступна по разрешённой этому месту проекции.

Размеры: 320×640, 390×740, короткий горизонтальный экран; руки 1/7/14/30 карт, крайний случай 35. Поверните телефон во время выбора чёрной карты: выбор остаётся, незавершённый жест отменяется и ход не повторяется. Проверьте touch-scroll большой руки без случайного хода.

Протокол защищает от повторного исполнения и устаревших команд. Общий и личный клиенты не загружают Session, правила игры или полные сохранения. Сервер раздаёт только разрешённый набор статических файлов и проекции, а не содержимое своего рабочего каталога. Паки остаются доверенным исполняемым кодом, не песочницей.

Звуковые и визуальные эффекты здесь не синхронизированы между устройствами по общим часам. Новый клиент получает актуальное состояние; повтор сообщения не должен повторять уведомление о доборе. Полноценные комнаты, долговечные сетевые сохранения и остальные четыре личных представления — следующий этап.

## Многооконный стенд MessagePort для разработки

Из исходников выполните `python3 -m http.server 4180 --bind 127.0.0.1` и откройте `/dev/multiview.html`. Выберите установочный JSON нового UNO (в комплекте `preview-packs/uno.playroom-pack.json`), создайте партию и открывайте окна кнопками. Вкладка организатора остаётся открытой.

Для разделения origin можно запустить второй статический сервер с теми же клиентскими файлами на другом порту и указать его origin в стенде. Передача канала проверяет origin, окно-источник и одноразовый идентификатор. Один origin сам по себе не является границей хранения; тест на одном origin не доказывает изоляцию от других доверенных страниц.
