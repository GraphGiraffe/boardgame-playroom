# ХОД 0.18.0-rc.7 · приёмка 2026-10-17

Кандидат приложения RC7 и коллекция 0.7.0-rc.5 предназначены только для защищённого preview и канала `0.18-rc.5`. Стабильная линия 0.17.6 / 0.6.5 не переключается. Проверенный preview: **https://3acb8786.playroom-hod-test.pages.dev**.

## Поведение

- Буква имени — 49-я квадратная ячейка выбора аватара, с доступным названием. Быстрые действия не содержат темы; ниже отдельная кнопка «Темы». Вкладка «Темы и скины» сохранена.
- Последняя игра в каталоге скрыта по умолчанию, включается `showLastGame` в локальных настройках. Карточки возврата к партиям остаются. У локальной карточки нет имени комнаты; прогресс рядом с названием игры обычным шрифтом.
- Компактные карточки и перенос участников без горизонтального скролла. Команды отдельными строками; общий компонент рисует аватары, хоста, первый ход и команды. Индекс библиотеки содержит только публичные сведения.
- Общий toast находится поверх видимой области, не прокручивает страницу и не уменьшает поле. Сохраняет закрытие и шестисекундное время показа.
- Дуэли всегда в ряд; сцены с `layout.seats`, включая Лудо, предлагают только углы и ряд. Углы в portrait: карточки сверху/снизу; в landscape: слева/справа у тех же баз, управление на стороне собственной базы. Дубль собственной карточки в landscape скрыт, поле использует всю высоту. `preferredSeating` отделён от временного fallback при реальной нехватке места; настройка не переписывается.
- Конфликт flex-basis=0 и flex-grow=0 сжимал карточки без рук в линии. Удалён запрет роста. Приоритет рук больше не перезаписывает трёхколоночную раскладку короткого landscape; имя и рука помещаются рядом.
- Motion отделяет локальную форму от экранного поворота родителей. Копия сохраняет размеры всего дерева, включая SVG, и масштабируется целиком. Добор/выкладывание отменяются с восстановлением видимости при resize; приватные лица не копируются.
- RoomService получает чистый порт `validateStart(room)` и общий `startBlocker(roomId)`. Приложение проверяет начальное состояние пака с фиксированным seed без создания сохранения. Свободные места допустимы при корректном составе; неподдерживаемый режим блокируется до отсчёта, потеря готовности отменяет старт.
- Морской бой 0.2.0-rc.5 / stateVersion 4 использует существующий timeline rounds: каждый выстрел — ход; переход очереди к начинавшему после соперника — новый раунд. Setup и завершение не создают лишних границ. Старые партии требуют свой точный immutable пак.
