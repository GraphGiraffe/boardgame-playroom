## Состав

- API 3, protocol 2; отдельные domain/presentation/locales/Web слои во всех 12 паках, независимые application controllers и platform adapters.
- Общая фиксированная сцена, действия/жесты/цели/эффекты/счётчики и повторно используемые наборы ассетов; безопасный масштаб и дискретные настройки.
- ЗиЛ+, 6 игроков в Змеях и Ятзи, подтверждение Ятзи, выбор фишки Лудо, компактные руки и сеты, разнообразные персонажи Пексесо.
- Финальная проверка устранила перекрытие соседней карты предпросмотром, изменение высоты руки, обрезку сетевой истории, слишком мелкие таблицы и цели на поле. Длинные таблицы и цепочки прокручиваются внутри постоянной области.
- Документация описывает текущую архитектуру и контракты. Будущие игры/скины только специфицированы, не подключены.

## Совместимость

Engine API 1/2 не исполняется; старые данные не конвертируются молча. Перед подтверждением полного перехода доступен экспорт. Опубликованные версии API 3 остаются неизменными для своих сохранений. Origin, защита и приватные данные сохраняются.

## Проверка и происхождение

Для стабильного перехода обязательны все семь блоков `core,input,games,ui,storage,network,pairing`, standalone pack build, SHA256/ZIP CRC локальных и скачанных релизов, protected production/runtime/catalog/offline. Итоговый протокол закрепляется за точной парой исходников в релизе. Снимки браузера покрывают телефон в обеих ориентациях, максимальный состав игроков, историю и состояния действий. Физические Android/iOS и поведение вырезов экрана остаются отдельной ручной приёмкой.

Production report содержит deployment ID, source commit, хеш PWA и проверенные версии/хеши каталога. Публикация коллекции печатает предыдущий snapshot до загрузки файлов; это точка отката каталога в паре с предыдущим Pages deployment. Процедура — [RELEASING](RELEASING.md).
