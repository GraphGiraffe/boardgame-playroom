# RC17 — панель действий и прокрутка игрока

Приложение 0.15.0-rc.17 поверх RC16 (dev a5e3de5). Паки остаются из коллекции 0.4.0-preview.8, CI закреплён за 5eb21b7d2a2cf0fd21f1f7a48703557f44bee22c. Stable и деплой отдельно.

## Поведение и интерфейсы

- `GameScreen.render` принимает `roomAction` с атрибутами существующего обработчика. Первый слот `data-game-primary` отображает комнату либо результат. Результат имеет приоритет; `historyResult` берётся из последнего состояния партии, а не выбранного кадра повтора. Независимые наблюдатели больше не добавляют комнату внутрь экрана игры.
- `GameScreen.addPlayerButton({disabled})` создаёт одну и ту же иконку addPlayer, стиль и доступное название для лобби и игры. Условия доступности сохраняются; сетевой слой вставляет кнопку после первого слота.
- Input находит ближайший реально прокручиваемый контейнер для X и Y отдельно: от руки к внешней `layout-self`, не выходя за панель. При начале скролла фиксирует ось и контейнер до отпускания, отменяет удержание/предпросмотр, подавляет случайный клик; границы не превращают скролл в ход. Удержание 220 мс на доступной фигуре по-прежнему включает drag. Мышиное колесо использует обычную прокрутку браузера.
- `touch-action: none` на панели согласован с общим обработчиком; перетаскивание и прокрутка доступны только вне inert-фона. Правила паков, сетевой протокол и сохранения не меняются.

## Воспроизведение и проверка

До исправления `tests/drag-app.test.cjs` воспроизвёл ошибку на реальной двухрядной руке домино 740×320: внешний контейнер переполнен, внутренняя рука не переполнена; жест по доступной костяшке не менял scrollTop. Старые тесты проверяли только внутренний скролл.

Проверяются реальные жесты по доступным/недоступным костяшкам, промежуткам и панели, независимые оси вложенных контейнеров, чужой ход, границы и обратная прокрутка. Панель действий проверяется в локальной истории, сетевом хосте и клиенте, до/после завершения и при начале следующей партии. Снимки 320/390 px и landscape сохраняются в отчёт.

Обязательный прогон: `bash scripts/codex/check.sh --full --packs-dir ../playroom-paks/packs`. Готовый защищённый ZIP дополнительно проверяется двумя браузерами. Физическая проверка RC17 на телефоне остаётся за пользователем.

Результат: полный совместный прогон **749/749**, 7 блоков, fail/cancelled/skipped 0, exit 0. Из готового защищённого ZIP прошли `drag-app` и `network-main-app`: **11/11**, exit 0. Дополнительная проверка достижения низа панели и обратного жеста в `drag-app` — **10/10**, exit 0. Контрольные суммы обоих архивов совпали; 51 файл runtime архива побайтно совпадает с исходниками.
