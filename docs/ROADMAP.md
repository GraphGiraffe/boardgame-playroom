# Roadmap после 0.18

## База 0.18

Готовы API 3 во всех 12 играх, независимые domain/presentation/locales/Web слои, общие компоненты и semantic assets, fixed scene, история/реакции/публичный Стол, независимая публикация приложения и паков, персональные темы/скины, bounded scale/audio/animation sliders. Игровые улучшения: ЗиЛ+, до 6 игроков в Змеях/Ятзи, выбор в Лудо, подтверждение Ятзи, компактные руки/сеты Рыбы, разнообразные персонажи Пексесо. Контракты — [индекс](DEVELOPER-INDEX.md); факт выпуска — [RELEASE-0.18](RELEASE-0.18.md).

## Патч 0.18.1: редактор настроек

В состав 0.18.1 включены два дискретных слайдера в строке, короткие названия и смысловые блоки правил, нижний блок завершения, ∞ в конце лимита раундов. Колоды остаются списками; Рыба — 36/52, Акулина — 35/51 в интерфейсе. В настройках руки/рассадки используются слайдеры, «Прямо»/«Веером»; справки «?» заменяют общий блок «О настройках». Companion — коллекция 0.7.1. Статус публикации — [RELEASE-0.18](RELEASE-0.18.md). Исходная база — стабильная 0.18.0/0.7.0. Доказательства — [PATCH-0.18.1](PATCH-0.18.1.md).

## Патч 0.18.2: сворачиваемые фильтры библиотеки

В состав 0.18.2 включено раскрытие фильтров по кнопке после «Все»/«Избранное»; по умолчанию группы скрыты, выбор сохраняется при сворачивании. Факт публикации — [RELEASE-0.18](RELEASE-0.18.md). Подробности — [PATCH-0.18.2](PATCH-0.18.2.md).

## Дальнейший backlog

- Внешняя сигнализация / reconnect после полного закрытия RTC; физическая матрица Android/iOS/desktop.
- Квоты пауз и опциональные часы хода через authority scheduler.
- Временная замена отключённого человека ботом и обратная передача места.
- Пользовательский чат/реакции, уровни ботов; отдельно от уже существующих игровых speech/reactions.
- Дополнительные сетевые/командные режимы и большие roster только при поддержке правил конкретного пака.
- Генератор шаблона пака и расширение SDK примеров, перенос сохранения на другое устройство.

Это будущие задачи, а не обещание функций стабильной 0.18.
