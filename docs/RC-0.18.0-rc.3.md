# 0.18.0-rc.3 — правки после проверки RC2

Кандидат выпускается отдельно от стабильной линии: приложение 0.18.0-rc.3, коллекция 0.7.0-rc.3, отдельный R2 channel `0.18-rc.3` и защищённый Pages preview. Main и production catalog не переключаются.

## Изменения

| Область | Реализация |
| --- | --- |
| Главное меню | Кнопки установки и присоединения — один вертикальный блок одинаковой ширины. На телефонах от 320 px сохраняются две колонки вертикальных карточек. |
| Редактирование | Общий SVG карандаша с отчётливым грифелем; кнопка порядка игр без текста, с title/aria-label. Общая иконка поля — контрастная доска с сеткой. |
| Тема | Справка UNO использует системную палитру вместо фиксированных светлых цветов. |
| Крупный ход | Внешний фиксированный слой; содержимое центрируется в видимой части `.layout-field`, обновляется при resize/scroll. Карточки игроков и статус не участвуют в расчёте центра. |
| Задержки | Одно удержание крупного хода: instant 200, fast 300, normal 500, slow 800 мс; вход/выход отдельно. Минимум обычной анимации ограничен политикой скорости. |
| Подготовка | Необязательный чистый callback `definition.preparing(position)` задаёт подготовительный этап. Durable revisions продолжаются, игровые ходы и раунды в этот момент не увеличиваются. |
| История | `timeline.playStart` задаёт начало просмотра ходов. Range и RPC используют исходные revisions; метки и видимый счётчик учитывают смещение. Статус показывает игровой ход, ползунок — действие, без дублирования подписей. |
| Просмотр истории | Панель просмотра не скрывается вместе с игровыми действиями. Общий controller изолирует viewState/preferences истории от текущей партии, ручной выбор не сбрасывается на границе хода. |
| Сеть | Authority передаёт публичную timeline в snapshot/history: ранее верхний уровень проекции терялся, хотя modelProjection содержала данные. Приватные проекции не расширяются. |
| Воспроизведение | Локальное и сетевое воспроизведение используют общую очередь feedback/reveal, отмена освобождает показ и его ожидания. |

Подготовка объявлена в Морском бое. Остальные текущие паки не имеют отдельной интерактивной расстановки до начала партии. Все паки получают новые immutable RC версии, поскольку общий CSS встроен в каждый bundle. Номера API/stateVersion не меняются; прежние опубликованные bundles остаются неизменными.
