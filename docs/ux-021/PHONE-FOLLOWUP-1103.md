## Сборка и проверка готового результата

Canonical app build:8SHA256SUMS и3ZIP CRC. Точная коллекция:27SHA и12ZIP CRC.230runtime-файлов текущего дерева совпадают с source ZIP; manifest проверен отдельно. Runtime не менялся после финальных проверок.

Готовый HTML прошёл **54состояния на движок** в Chromium/WebKit: корневые экраны, Эффекты, оформление, виды каталога, правила, лобби, партия, статус/меню/Stop-Cancel, аккаунт. Ошибки, failures и nativeSupabaseRequests пусты/0. Дополнительно на финальной PWA пройден gallerycase в обоих движках: реальный touch вызова собственного списка, keyboard/focus, поля/черновики,12цветов в двух темах, маркеры и закрытие снаружи. Это выбранные сценарии, не полный прогон всех игр/ролей.

Source-проверки сохраняются в перечисленных отчётах: Лудо и UNO deadlines, actual local mobile input +13существующих UNO subcases, lobby RTC/Community/Unified и командные ограничения, audio engine/feedback/first native touch. Физический iPhone не подменяется WebKit: для части жестов WK использованы контролируемые pointer/mouse/keyboard, что явно указано в отчётах.

Все артефакты: `tmp_files/ux-021/phone-followup-1103/final-manifest.json`, source-state, artifact-final, gallery-final-* и public-check. Временный Funnel443/8443 и /hod-021.html обновлены; публичные index/SW/HTML совпали. Живой новый worker activated, точный cache,15игр/PushManager. Первая8sпроверка сетевой загрузки дала timeout; повторная с30sдля первого bootstrap прошла без продуктовых/сетевых изменений. Причина задержки не выдаётся за установленную.

Это размер файлов, а не обещание такого же занятого места браузером: там отдельно хранятся установленные архивы и сохранения. Самостоятельные пакеты используют их независимо; автоматически удалять такие данные как «мусор» нельзя. Удалён только CSS с отсутствующими в приложении классами. Архивы исходников, снимки и прошлые кандидаты не входят в размещённую PWA. Дополнительный аудиторский срез: `tmp_files/ux-021/account-ready-checkmarks/size-audit.json`.
