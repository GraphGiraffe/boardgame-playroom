# Уточнения владельца после просмотра реального кандидата

Последние указания переопределяют соответствующие детали прототипа0.21;
это продолжение реализации, не разрешение публикации или production SQL.

- Общий Аккаунт из карточки профиля: локальные имя/аватар и облачные функции
  доступны в одном окне, без отдельных footer Account/Logout; явный тип
  «Локальный аккаунт» / «Облачный аккаунт».
- Фильтры Моих партий видны над списком, без management disclosure.
  Точечное пояснение о недублировании уведомлений удаляется.
- Refresh чатов/друзей не вставляет сверху меняющие layout статусы;
  сохраняются native input, selection, scroll и строка списка.
- Перетаскивание показывает корректный ghost на desktop/touch и очищает его
  при drop/cancel/смене экрана. Порядок игр редактируется drag и кнопками
  в управлении играми; Выше/Ниже в одной строке, у всех действий иконки.
- Главный каталог: явный режим редактирования, drag + скрытие/избранное,
  без стрелок вверх/вниз. Последняя карточка имеет ту же сетку, что остальные.
- Root/modal scrollbar не сдвигает композицию. Native overlay где доступен;
  для classic — стабильная симметричная область и тонкая полоса.
- Все места лобби видны, компактно2колонки, номер по canonical seat.index,
  выбор цвета/места и жетона первого игрока согласован с этим порядком.
- Правила: открытые блоки Порядок игры → Параметры → Завершение, без общего
  скрывающего всё spoiler, параметры в2колонки где помещаются.
- Краткие правила действительно краткие: цель, основы и ход + содержательные
  картинки реальных компонентов. Полные правила сохраняются отдельно.
- Обычные опасные menu rows спокойные с иконкой/акцентом текста, без сплошных
  красных прямоугольников; явное подтверждение сохраняет главный danger CTA.
- Единая сетка экранов/панелей/окон: заголовки, возврат и правые служебные
  кнопки выровнены. Заголовок партии получает обложку и полезные quick actions
  по реальным возможностям, без отъёма места у поля/руки и без лишних дублей.

Проверяется применимость этих паттернов во всём интерфейсе; исправления
конкретных скриншотов не заменяют общих компонентов. Новые требования остаются
в работе до source, актуальных targeted checks и просмотра готового артефакта.

## Проверка анимаций и обратной связи

Проверяются полный вход и выход панелей/окон/уведомлений, повторное открытие
во время закрытия, быстрый возврат, touch/keyboard, normal/reduced motion,
исключение кликов по уходящим поверхностям и немедленная очистка при смене
аккаунта/reset. Игровые анимации и transforms компонентов не заменяются
общими эффектами интерфейса.

Карточки партий уже возвращены к постоянной информативной компоновке:
действия открываются отдельно, исходная карточка не сдвигается. Адресная
проверка Chromium/WebKit на320/390/844 подтверждает сохранение DOM и геометрии.
Отправка личного/группового сообщения показывает ожидание в закреплённой кнопке,
сохраняя ввод и повторную отправку; состояния Push видны в существующей строке,
приглашение показывает «Отправляем…». Соответствующие existing cases прошли
в обоих движках; реальных рассылок не выполнялось.
