# Каталог отдельно от приложения · preview.21 · 2026-11-06

PWA теперь собирается без встроенной коллекции по умолчанию, даже если builder
получает --packs-dir и --all-games. installed-packs содержит пустой список.
Полный playroom-all-games.html остаётся отдельным явно выбранным переносимым
артефактом. Публичные standalone preview-маршруты теперь используют playroom.html
без игр; галерея и калибровка сохраняют прежние маршруты.

На сайте preview отдельно доступен стандартный API /api/packs/catalog и
/api/packs/files/<id>/<version>/<sha256>.playroom-pack.json. Это статический
preview-каталог, не публикация в stable R2/catalog. Он содержит 15 прежних
проверенных паков; правила, ассеты и версии паков не менялись. Перенесены те же
логические bundles из проверенного preview.20; индивидуальные файлы имеют
собственные SHA256. В каталоге есть имена и release notes, но нет исполняемых
правил/ассетов. До выбора игры запросов её файла нет.

Удалён стартовый автозагрузчик, который при пустой библиотеке скачивал весь
каталог без выбора пользователя. Пустая библиотека открывает «Доступно»;
подсказка предлагает выбрать игры. Кнопки восстановления встроенных нет при
пустом встроенном списке. Ранее установленные версии и партии сохраняются в
сжатом durable snapshot, загружаются без повторной установки и работают офлайн.
Ответы API файлов не попадают в CacheStorage: SW пропускает этот API, fetch
использует cache:no-store. Поэтому второго пакета правил в кеше оболочки нет.

Причина показанных владельцем ошибок: preview раньше не обслуживал API каталога,
поэтому он возвращал 404, а общий результат проверки приложения/игр назывался
«Не удалось проверить все обновления». Теперь API доступен на обоих PWA origins
и web standalone origin. При реальной ошибке источника статус явно различает
проверку приложения и игр. Найденное обновление приложения не теряет доступную
подготовку из-за ошибки каталога; сообщение не выдаёт неизвестный статус игр
за отсутствие обновлений.

Размер shell payload: 6189761 → 3656077 байт UTF-8, около 5,9 → 3,5 МиБ.
Реальная адресная браузерная проверка с установленными 15 играми: приложение
3679933 байта, паки 1006784, итого 4686717. Это значения payload, не физические
страницы БД/весь профиль браузера; конкретные предпочтения и metadata дают
небольшую разницу. На телефоне объём обновится после установки новой PWA и
удаления старого кеша штатной активацией SW.

Проверки: SHA/manifest rejection в загрузчике; новая PWA с нуля, отсутствие
автозагрузки, установка первого пака настоящей кнопкой, всех 15 точных паков
через общий проверяемый порт, отсутствие второй копии в CacheStorage, офлайн
перезапуск и запуск UNO; .20→.21 с сохранением партии и offline; реальные
экраны проверки обновлений с частичным 404, доступным обновлением, offline,
отменой/таймаутом и сохранением UI-владельца. Полные наборы/Actions не запускались.
Первый новый сценарий действительно обнаружил автозагрузчик; начальные ошибки
и итоговые успешные логи сохранены в tmp_files/catalog-only-1106/.

Публикация, точные SHA/команды/версии: publication.json и provenance.json в том же
каталоге. Физическая приёмка Android/iOS остаётся открытой; новых Chrome-снимков
нет. Старые публикации, пользовательские данные и общие службы не очищались.
