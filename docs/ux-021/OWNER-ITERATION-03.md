# Ревизия владельца03: реальный телефон, 02.11.2026

Эти указания важнее прежних соответствующих решений прототипа и итерации02.
Работа возобновлена по новым замечаниям; это не разрешение публикации/SQL.

## Требования

1. Общие заголовки: иконка слева от названия; Назад и полный экран сверху справа.
   Название допускает две строки, статус — одну. Одинаковая сетка и области
   нажатия без пересчёта композиции после появления окна. В игре сохраняется
   квадратное поле, в landscape резерв под tools только в зоне игрока.
2. Все фильтры сразу видны, без «Точного подбора» под спойлером. Открывающий их
   элемент выглядит иначе, чем выбор Все/Любимые. Карточки каталога остаются
   квадратными и одинаковыми; legacy featured не меняет их структуру.
3. Вызов чата справа, у строки собственных жетонов/здоровья, с фоном страницы.
   Не перекрывать значения/карты; сохранить tap/pull и увеличение истории.
4. Панель закрывается свайпом вниз из любого свободного места, не только ручки.
   Чаты/списки/контролы/редактирование и их прокрутка не становятся dismiss-жестом.
5. «Добавить бота» без указания средней сложности; сама стартовая сложность
   остаётся прежней. Пауза и возврат на главный видны без спойлера меню.
6. Тап по карточке в Моих партиях открывает все доступные действия, включая
   продолжение. Не нужно искать действие свайпом; полезная информация постоянна.
   Ошибка получения из облака должна быть видимой, с сохранением локальных данных
   и явным повтором. Fixture success не доказывает доступность внешнего сервера.
7. Обновить список общения можно быстрым действием сверху. Отдельный режим/кнопка
   порядка убираются: удержание на карточке чата начинает перестановку с ghost.
   Новое самостоятельное нажатие после drag/cancel не должно теряться, а старый
   compatibility click — случайно открывать разговор.
8. Удержание карточки Потасовки показывает только её текущее действие и схему
   в текущем направлении, без перечня остальных режимов. При смене описанного
   состояния старое удержание отменяется. Полные правила остаются отдельно.
9. Проверить торможение, особенно fullscreen: измерять реальные повторные
   layout/render вызовы, исправлять источник; не добавлять слепые задержки.
10. Корневой «Профиль» переименовывается в «Параметры» с иконкой шестерёнки.
    Внутренний profile ID и сохранённые настройки не мигрируют ради подписи.

## Дополнения во время приёмки

- Карточки Моих партий уплотняются объединением room/mode и progress/actions,
  без удаления метаданных; участники переносятся по необходимости.
- Полный экран — только у экранов, включая корневые и партию. Панели, диалоги,
  окно действий/фильтров и чат не получают эту кнопку. Назад остаётся справа.
- Быстрый вызов истории убирается из шапки партии; сама история остаётся в меню
  партии и действиях сохранения.
- В Параметрах: «Игры», «Обновление»; «Уведомления» сразу после Оформления.
  Последний пункт — «Установить ХОД», скрытый при известной установленности.
  Это отменяет промежуточное предложение названия «Установка».
- Состав игроков в фильтре — прежние иконки; пресеты Все/Для двоих/Компания
  удаляются, все остальные группы остаются открытыми. Центр звезды избранного
  проверяется относительно круговой подложки и общего SVG, без browser offsets.
- Провести аудит frontend/backend лишних действий, копий и передачи данных.
  Измеренные P1 устраняются с сохранением privacy/idempotency; немеренные
  кандидаты/необходимые снимки отделяются в отчёте.
