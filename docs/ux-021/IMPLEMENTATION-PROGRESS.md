## Зафиксированные новые решения

- Вид каталога и вход в комнату на одной строке; строки, квадратные сетки 2/3.
  Избранное сверху даже при включённой недавней игре; звезда справа сверху.
- Порядок режимов: На устройстве / Онлайн / Рядом. Это заменяет прежний online-first.
- Краткие правила читаются прокруткой, полные имеют закреплённое раскрываемое оглавление.
  Markdown компилируется существующим pack compiler; произвольный HTML не исполняется.
- Чтение правил и редактирование настроек — отдельные действия лобби.
- Контекстные (?) остаются рядом с параметрами. Глобальный перечень правил не нужен.
- Аккаунт: никнейм, имя аккаунта, email, изменение и восстановление пароля.
- Активные партии обозначаются бейджем на вкладке истории.
- Старая палитра: бежевый светлый фон, чёрный тёмный; существующие семантические иконки.
- Экран партии переносится с действующего игрового renderer, сохраняя руки, анимации,
  квадрат поля и роли зон: landscape — оппоненты слева, игрок справа.
  Схематическое поле из HTML не заменяет боевой renderer.

## Реализовано в этом этапе

Каталог: сохранение вида, общая строка действий, компактная сетка, читаемые заголовки,
приоритет избранного. Бейдж известных сохранённых активных партий. Порядок режимов.
Краткая/полная версия правил, оглавление, возврат к краткой версии. Никнейм в форме
имени аккаунта; восстановление пароля доступно авторизованному пользователю.
Исправлен CSS-приоритет поворота в отдельном прототипе.
