# Удаление последнего пака и проверка связи · preview.22

Владелец показал пустые корневые экраны и съехавшие вкладки после удаления игр,
а также «Нет сети» в проверке приложения при работающем каталоге.
Приватное видео изучено четырьмя кадрами в tmp_files/delete-games-1106/;
новых Chrome-снимков нет, attachments не входят в Git/public.

## Причины и исправление

Корневой hub использовал shared-page-deck/panel. Правила размещения приходили
из CSS установленного пака (канонический packs/shared/view-kit.css включён в
каждый пак). При удалении последнего пака его style-узел исчезал. Неактивные
разделы становились обычными скрытыми блоками в потоке, а активный оказывался
ниже них. Репродукция без паков: sessions +415px, social +769px, profile +1191px
от начала deck. После установки паков размещение восстанавливалось, после
удаления через настоящий UI ломалось снова; после reload ошибка сохранялась.

Оболочка теперь сама определяет только свой корневой deck: позиционирование,
движение, изоляцию margin и reduced motion. Геометрия не зависит от game CSS.
Канонический SDK/паки не изменены и не копируются целиком в приложение.

Ручная проверка обновлений отказывала сразу при navigator.onLine=false.
Этот системный признак не подтверждает недоступность origin через VPN.
Репродукция с работающим сервером и ложным флагом возвращала code:offline.
После удаления раннего отказа обнаружилась вторая граница: registration.update()
может завершиться успешно офлайн из-за объединения проверок браузером.
Теперь перед ним выполняется HEAD запроса к точному scriptURL регистрации,
cache:no-store и redirect:error. HEAD не перехватывается GET-only shell cache,
не скачивает тело worker и не создаёт ещё одну кешированную копию. Неуспешный
реальный ответ или network error остаются ошибкой. registration.update и
ожидание waiting-worker metadata по-прежнему обязательны.

## Доказательства

before.json: оба первоначальных дефекта на точном опубликованном .21.
after-before-head.json/log: геометрия уже исправлена, но новый сценарий показал
успешный update() офлайн — этот промежуточный результат не считается зелёным.
after.json: все четыре страницы до установки, после установки всех 15 паков,
после удаления через UI и после пустого reload имеют relative/offset 0;
ложный offline flag не препятствует настоящему запросу, реальная потеря сети
даёт TypeError, после восстановления проверка успешно повторяется.

Дополнительно выбраны существующая корневая навигация в portrait/landscape и
настольной rail, а также обновление PWA .21→.22 с сохранением партии/offline.
Итоговые команды, точные исходники, pass/fail/log SHA и публичная сверка находятся
в tmp_files/delete-games-1106/provenance.json и publication.json. Полные наборы
и Actions не запускались; физическая Android/iOS приёмка остаётся открытой.
Существующие пакеты, пользовательские данные, каталоги и службы не очищались.
