# Включение уведомлений: отсутствующий worker в Funnel-превью

03.11.2026. Запись Screen_Recording_20261103_000329_Chrome.mp4 (5.875с) показывает отключённое управление с текстом «Откройте установленное приложение или сайт». Этот текст соответствует коду `pwa-required`, а не запрету разрешения или ошибке VAPID. PushDevice требует активную регистрацию worker; опубликованный каталог Funnel содержит только `index.html`, без `sw.js` и `platform/web/push-worker.js`. Синхронизация Push прерывается до получения серверной конфигурации.

В PushUI причина заменена на точную: служба уведомлений не запущена в этой версии сайта; нужна полная веб-версия. Добавлена явная «Повторить проверку», которая повторно проверяет текущую учётную запись и службу. После появления worker/config управление становится доступным. Повторная проверка сама не вызывает разрешение браузера и не оформляет подписку: включение требует отдельного нажатия.

Существующий case `web push settings opt in explicitly, revoke on logout and navigate using authorized target` расширен последовательностью missing worker → повтор без worker → появление worker → повтор → явное включение. Chromium1/1 и WebKit1/1, ошибок0. Провайдеры изолированы, реального Push/permission не было. Отчёт и contact sheet: `tmp_files/ux-021/notifications-enable/`.

Для фактического ремонта публикации нужен полный canonical PWA-комплект: `sw.js`, неизменённый `platform/web/push-worker.js`, fingerprinted JS/CSS, index, manifest/icons и integrity. Параметр `--remote-catalog` только заменяет список предустановленных паков пустым; SW/Push не вырезаются. Приложение получает Push config отдельным account-scoped RPC, поэтому наличие worker устраняет показанную причину, но само по себе не доказывает готовность VAPID/backend или доставку. Публикация здесь не выполнялась.
