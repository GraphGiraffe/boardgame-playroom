# Регионы Лудо — 4 ноября 2026

Статус: renderer перенесён на регионы, локальные игровые проверки окончательного HTML пройдены. Временные публичные маршруты обновлены, но запуск и offline через внешний HTTPS пока не подтверждены. Полная GOAL 0.21 остаётся открытой.

## Изменение и границы

В canonical `playroom-paks/packs/ludo/view.js` выделены независимые регионы клеток, фишек, баз, центра и кубиков. Для четырёх игроков и двух кубиков это 99 регионов: 76 клеток, 16 фишек, 4 базы, центр и 2 кубика. Вызов построителя выполняется только при изменении зависимостей региона; без поддержки регионов сохраняется статeless full-HTML путь. Зависимости учитывают разрешённые цели, выбранную фишку, положение, состав стопки, подпись, viewer и контекст показанного броска.

При повторном неизменённом представлении построители фишек и кубиков вызываются 0 раз вместо 16 и 2. Выбор другой фишки и ход перестраивают затронутые компоненты; результат совпадает с актуальной полной разрешённой разметкой, включая занятую дружественную клетку. Это не доказательство устранения полного внешнего recipe, обхода всех зависимостей или ускорения всей игры: эти ограничения остаются.

Правила, игровые CSS и shared assets не менялись. Все 230 файлов runtime приложения совпадают с предыдущим кандидатом FRAGMENT-IDENTITY. Изменился generated companion; другие 14 объектов паков JSON-идентичны предыдущей сборке. Сборка коллекции 0.8.9-preview.6, Лудо 0.3.7-preview.4.

Это подтверждает доступность одного HTTPS-запроса, но не объясняет сбой браузеров и не доказывает работоспособность публичной PWA. Проверка сертификатов не отключалась, службы/соединения не перезапускались. Исходные неудачные отчёты сохранены; публичный запуск остаётся незакрытым пунктом.
