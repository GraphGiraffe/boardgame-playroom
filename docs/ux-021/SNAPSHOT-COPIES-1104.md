## Изменение

`core/model-values.js` повторно использует только корни снимков, которые этот же модуль уже скопировал, проверил как JSON и глубоко заморозил. Приватный WeakSet не удерживает недостижимые снимки. Внешние объекты, включая shallow/deep frozen, проходят прежнюю проверку и независимое копирование; `copy()` продолжает возвращать изменяемую независимую копию.

`core/model-registration.js` готовит immutable-позицию на границе адаптера. Внутри одного синхронного вызова resolveAction/legal/reactions/botReaction она используется повторно. Между вызовами, ревизиями и зрителями позиции не кэшируются. Проверки правил и прав не пропускаются, исходное состояние не отдаётся callback-функциям. Форматы сохранений, паков и протокола не менялись. Остальные ранее существовавшие изменения этих файлов сохранены; собственный diff записан отдельно.

## Измерение и отклонённый вариант

Использован прежний controlled-artifact-replay: seed17, одинаковые состояние/действие/точка, Spider,740×390, Chrome156,1×CPU, normal340ms, soundoff. Под профилировщиком воспроизводится один законный ход, без реальных сервисов.

| Вариант | Native click EventDispatch |
|---|---:|
| Опубликованная до правки764ea7, две контрольные записи |89,97 /89,44мс|

Первый вариант добавлял издержки и не опубликован. Окончательный устраняет конкретные повторные копии, но **не доказывает улучшения общей задержки**:90,20мс соответствует исходным значениям с учётом разброса. Самосэмплы snapshot исчезли из одной CPU-выборки; это не означает нулевую стоимость всего model layer. Прогонов недостаточно для распределения INP, статистической оценки, FPS или скорости физического телефона. Остаточная длинная задача около100мс не закрыта.
