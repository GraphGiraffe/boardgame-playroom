# Дополнение к аудиту: масштабирование текста Data и библиотеки

Обычный текст в `cloud-saves.css`, `pack-manager.css`, `packs-021.css` переведён из px в rem относительно стандартного корня16px. Исходные размеры при16px сохранены. Рисунки, жетоны, физические обводки и графический знак ручки перетаскивания не изменялись. Основание — [web.dev: относительные единицы и доступное масштабирование](https://web.dev/articles/accessible-responsive-design); рекомендации применяются вместе с согласованными макетами, а не вместо них.

Старая экспортируемая `GameScreen.fitGameTitles` больше не уменьшает шрифт и не подменяет полное название коротким. Существующие inline размеры снимаются; у старого table-title сохраняется скрытие подписи режима при двух строках. CSS заголовка лобби допускает две строки. Современный game-frame имеет собственную общую типографику; эта правка не выдаётся за исправление наблюдавшегося дефекта всех игровых заголовков.

## Найденный дефект переноса

Расширение существующего геометрического сценария библиотекой игр выявило одинаковый RED в Chromium и WebKit:320px, text200, вкладка «Установлено» имела clientWidth143px и scrollWidth174px. Явные `white-space:normal;overflow-wrap:anywhere` на вкладках библиотеки разрешают перенос, сохраняя размер текста и минимум44px. Исправление не сокращает название и не прячет пункт.
