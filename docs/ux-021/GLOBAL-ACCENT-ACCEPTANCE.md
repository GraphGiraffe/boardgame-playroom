# Общий акцент приложения

Уточнение владельца 3 ноября: менять акцент всего приложения, а не только цвет поля.

AppearanceService хранит accentColor; прежний fieldColor переносится при чтении, новое явно заданное значение (включая null) имеет приоритет. Запись атомарна, встроенные темы не меняются. Название настройки — «Акцент приложения». Тема и выбор цвета применяются сразу.

AppearanceWeb выводит общую action/focus/selection/hover/border палитру, включая совместимые алиасы --green/--accent/--lime. Canvas остаётся бежевым/чёрным, player-slot и feedback error/success сохраняются. Нестандартный основной оттенок адаптируется к теме: контраст текста/заливки основных действий и accent-текста на основных поверхностях >=4.5. Зелёный по умолчанию восстанавливает точные встроенные токены.

Проверки: существующие appearance unit 14/14; расширенный gallery case source Chromium/WebKit по1/1, затем тот же case на точной PWA global-accent/final по1/1.
