## Начало SDK и границы доказательства

[PACK-SDK-LAYOUT.md](../PACK-SDK-LAYOUT.md) описывает реальные экспериментальные host exports `landscapeZones`, `alignInZone`, `zoneOutline` и `layoutPreset: 'tableau-wings'`. Они не означают готовность всего SDK, всех alignment helpers или миграцию каждой игровой механики. Сохранены API 4 / viewApi 3 / protocol 3 и граница авторизованной сцены.

На момент составления реестра в `game-screen-test.log` зафиксировано 28 passed / 0 failed, а `final-build.log` сообщает о создании offline HTML и PWA. Это локальные проверки конкретной версии исходников; их совпадение с окончательным кандидатом после любых последующих правок должно быть подтверждено основным отчётом. Старые `captures-first.json`/`build2` не являются доказательством final.

Не подтверждены этим документом: полная матрица 15 игр × 2 состава × режимы/ориентации; окончательная визуальная приёмка всех 20 записей; поведение реального S23 и выреза экрана; длительная партия/память/CPU; фактическая слышимость звуков; все обучения и drag-and-drop; реальная сеть и входящие сообщения; публикация или изменение Funnel. Для каждой области нужен соответствующий результат, а не вывод из успешной сборки.

## preview.9 — единая карточка и аватары участников

Для стандартной рассадки оставлен один вариант карточки: аватар слева, имя и счётчики справа в двух строках. ## preview.11 — рамка хоста и аватар hotseat

По уточнению пользователя хост отмечен золотой рамкой вокруг аватара. Рамка не меняет размеры/отступы; корона хоста удалена из разметки, векторный значок сохранён в библиотеке и остаётся доступным играм. Отметка рамки синхронизируется с isHost при обновлении сетевого присутствия.
