# Печать номиналов и безопасные зоны карт — 4 ноября

Исправления общего рендерера и скинов, без изменения шрифта, размера карт в руке или масштаба игрового стола. Дополнение к [полному отчёту](FULL-REPORT-1104.md). Полная цель 0.21 остаётся открытой.

## Изменения

- Угловые индексы стандартной колоды рисуются отдельным прозрачным слоем **поверх рамки**, вне обрезки иллюстрации. Центральный рисунок остаётся ограничен скруглённой поверхностью. Рубашка, физическая форма, глубина и подсветка сохраняются. Оба угла используют одну печать с поворотом на 180°.
- Классический индекс выровнен по левому отступу альтернативного. Вертикальные позиции номинала и масти классического скина сохранены. Масть альтернативного индекса имеет постоянную позицию рядом с номиналом.
- «10» сжата по горизонтали в пределах одного номинала: сохраняются используемый шрифт, высота и вес. Для классического и альтернативного индекса ширина составляет 10 единиц их артборда; для крупного скина — 20 единиц его артборда. Новый шрифт и отдельный шрифт для единицы не вводились.
- У классических скинов уточнена безопасная область масти; минимальное вертикальное раскрытие увеличено с 0,35 до 0,38 высоты карты. У крупного скина уточнена область номинала. Для всех шести скинов границы заявленных зон укладываются в horizontal/arc/vertical exposure.
- Горизонтальное перекрытие сброса пасьянсов теперь берётся из выбранного скина. Ранее там стояла константа 0,34, которая не соответствовала крупному скину с экспозицией 0,5. Ширина сброса учитывает число видимых карт. При смене оформления обновляются горизонтальный и вертикальный шаги, а также ось сброса. Альтернативный скин сохраняет вертикальное раскрытие.

Канонические изменения находятся в `playroom-paks/shared`; host-копии обновлены companion-сборкой. Внешний API игровых значений и логика игр не менялись. Коллекция получила preview-версию 0.8.9-preview.14; версии всех 15 паков увеличены, поскольку общий каталог ассетов входит в их переносимые ресурсы. Прежние байты превью сохранены. Stable и R2 не публиковались.

## Проверки

Evidence: `tmp_files/ux-021/card-print-layer-1104/`.

1. Готовый автономный HTML, Chromium и WebKit: по **312 образцов** — 13 номиналов × 4 масти × 6 скинов. Границы угловых индексов/крупного номинала входят в защищённые области, слой индексов расположен после рамки, верх и низ стандартной карты имеют одинаковую печать. Центральная крупная масть может перекрываться согласно авторской зоне распознавания; полная видимость центральной иллюстрации не требуется.
2. Компонентные стенды, оба движка: по **24 сцены** — шесть скинов, две ориентации, рука Дурака и стопки Косынки. В Косынке проверены три открытые карты в колонке и три карты в сбросе. Проверяется попадание указателя в ту же карту во всех углах прямоугольников индексов; наложения соседей не обнаружены. Положение проверочной руки и ограниченный контейнер пасьянса не являются продуктовой компоновкой.
3. **Штатный запуск приложения**: выбор игры → «На устройстве» → «Начать партию», затем смена оформления через работающий сервис. Для Дурака и Косынки проверяются все шесть скинов на 360×740, 390×844 и 844×390: по **36 проверок на движок**. Индексы остаются видимы, страница не выходит по горизонтали за viewport. Снимки с `-actual-` в имени относятся к этому пути. Для Chromium при ширине 390 карта Косынки имеет размер 48×67,2 CSS px; bbox повёрнутых карт руки Дурака около 62–64×86 CSS px. Поворот меняет bbox, поэтому это не отдельное изменение пропорций карты.
4. `case/domain-foundation --name 'shared component and sound resources are pinned to canonical sources and resolve skins locally'`: 1/1 PASS. Проверена синхронизация канонических shared-компонентов с host.

Ранние неуспешные стенды сохранены в локальных логах: неполное состояние Дурака заменено существующей валидированной фикстурой; прямой render пасьянса не восстанавливал продуктовый контроллер геометрии; штатный запуск уточнён с обязательным экраном выбора режима. Первые стендовые снимки с маленькой рукой не являются финальной компоновкой. Они не учитываются как доказательство размеров приложения.
