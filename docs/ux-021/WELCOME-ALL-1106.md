# Первое приветствие и «Установить все» · preview.25

## Поведение

Вкладка «Доступно» предлагает «Установить все» для отсутствующих игр. Очередь
использует тот же проверяемый SHA256/manifest порт и компактные строки, что и
одиночная установка. Общая кнопка показывает прогресс, повторный клик во время
загрузки не запускает вторую очередь. Ошибка отдельной игры не удаляет успехи;
последующий запуск выбирает только оставшиеся игры. Обновление существующих
версий остаётся отдельным действием. По завершении нет перехода в сводку.

На первом пустом веб-запуске приветствие содержит установку приложения ХОД и
отмеченную по умолчанию загрузку всех игр. До подтверждения имени/выбора файлы
игр не скачиваются; метаданные каталога можно читать заранее. Можно снять
отметку, начать с пустой библиотекой и выбрать игры отдельно. Для файловой копии
загрузка из каталога недоступна и опция отключена. При уже имеющихся играх
предварительная отметка не включает дополнительную автоматическую установку.

Установка приложения использует существующую owned install UI: настоящий
beforeinstallprompt/prompt/userChoice или инструкцию меню браузера/Safari.
Нативный диалог не подделывается, accepted не означает доказанную установку.
При известной установке предложение скрывается. Первый черновик имени и отметки
сохраняется при выходе из дочернего окна установки. Защита несохранённого имени
проверяет активный profile-form, не блокирует возврат из его дочерних окон.

После подтверждения отмеченной коллекции открывается «Доступно», метаданные
загружаются и один раз запускается очередь отсутствующих игр. При недоступном
каталоге показана возможность повторить проверку; незаметной установки после
ухода с этого экрана нет. Начатая пользователем очередь может закончиться в фоне,
не открывает прежнее окно поверх нового. Следующее посещение не повторяет
приветствие и не включает скачивание заново после отказа.

## Проверки и границы

- Bulk: одна заранее установленная игра, удержанная загрузка, повторный клик,
  повреждённый файл одной игры, продолжение остальных и повтор только недостающей;
  все 15 игровых файлов в итоге загружены по сети по одному разу.
- Первое приветствие без fixture-профиля: app offer/родной installation UI,
  возврат с точным DOM черновика; 320/390/844 без горизонтального переполнения;
  до согласия 0 файлов, после согласия 15 игр и offline reload; отказ оставляет
  0 игр, загрузок и повторных приветствий после reload.
- Одиночная установка сохраняет карточку/кнопку/прокрутку и явное обновление списка.
  PWA .24→.25 сохраняет партию и offline. Шесть unit-сценариев PWA installation port
  проверяют приглашение, однократность, состояния iOS/native/installed и stale probe.

Итоговые log SHA, исходники, Build/SHA/ZIP и live publication:
`tmp_files/welcome-all-1106/provenance.json`, `publication.json`.
Паки/каталог/версии игр не менялись, встроенных паков 0. Нет full suite/Actions,
stable/R2/protected publication и новых Chrome-снимков. Физическая установка на
Android/iOS и полная телефонная приёмка остаются отдельной непроверенной границей.
