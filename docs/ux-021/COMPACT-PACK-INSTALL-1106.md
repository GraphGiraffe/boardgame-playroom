# Компактная установка игр · preview.23 · 2026-11-06

Владелец показал ручную установку из «Доступно», которая открывала сводку
«Игры обновлены» с очисткой старых версий и длинной историей изменений.
Видео изучено ключевыми кадрами в приватном tmp_files/pack-install-1106/;
новые Chrome-снимки не создавались, пользовательские файлы не входят в public/Git.

## Поведение

- Карточка в «Доступно» использует размер/оформление списка «Установлено»:
  art-зона, имя, версия/размер, краткое описание, компактная icon-кнопка.
  Размер кнопки соответствует общему --ui-target (44px на узком экране,
  штатные 46px на широком), а не полноширинному CTA.
- Загрузка, успешная галочка, ошибка и повтор меняют состояние этой кнопки/строки.
  Нет переоткрытия окна, автоматической смены вкладки или перехода на сводку.
  Успешная строка остаётся на месте до нового открытия менеджера; игра также
  присутствует в «Установлено». Сохраняются DOM-карточка/кнопка/рамка, прокрутка
  и раскрытые сведения. Ошибка показана у своей игры, повтор использует тот же
  проверяемый SHA256 порт. Reduced motion соблюдается.
- Описание берётся из tagline. Закрытый спойлер содержит только последнюю
  подходящую release note; весь архив изменений в карточку не выводится.
- Каталог/канонический publisher передают name/tagline/tileTheme/byteSize без
  исполняемых файлов игры. Валидатор проверяет текстовые поля и размер.
  Коллекция/версии/bytes всех 15 паков не менялись, встроенных паков по-прежнему 0.
- Ручной import остаётся с явным просмотром доверенного файла, но тоже не
  открывает лишнюю сводку обновления. Мёртвый packsOnly-путь сводки удалён;
  настоящая сводка после обновления приложения сохранена.

## Очистка после обновления приложения

При отсутствии старых версий кнопка имеет hidden и действительно display:none:
раньше общие стили .btn перекрывали браузерное скрытие. Короткая подпись
«Очистить» имеет полное aria-label «Удалить старые версии игр». После успешного
removeUnused окно закрывается и квитанция обновления подтверждается.
При ошибке окно остаётся с сообщением и возможностью повтора. Ссылки сохранений,
активные версии и ownership guards сохранены.

## Проверки

До исправления compact-case падал на ширине 324px вместо компактной кнопки;
cleanup-case на старом .22 подтверждал видимую кнопку при пустом плане.
Итоговый install-case проверил описание, одну release note, удержанную загрузку,
тождество DOM, открытый спойлер, неизменность y/scroll, ширины 320/390/844,
ошибку контрольной суммы и успешный повтор. Зафиксировано y=333.90625 и scroll=1036
до/после установки. Проверены пустая/непустая очистка с сохранением партии,
реальный import/remove/quarantine, PWA .22→.23 и offline, unit metadata publisher
и SHA/URL/manifest/metadata validation. Общий список installed версий строится
один раз на render доступных строк вместо повторных clone manifest для кнопок.

Прежние успешные проверки не повторялись при правках вне их scope; все
промежуточные неуспешные логи сохранены отдельно. Полные наборы/Actions не запускались.
Итоговые исходники, логи/SHA/ZIP, каталог и публикация: provenance.json,
publication.json, catalog-provenance.json в tmp_files/pack-install-1106/.
Физическая Android/iOS приёмка остаётся открытой.
