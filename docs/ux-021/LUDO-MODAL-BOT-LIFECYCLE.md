# Локальный бот и обычные экраны поверх партии

Воспроизведение: canonical Ludo solo seed 11, у бота одна фишка вне базы; настоящий бросок выдаёт 2/5. Во время представления броска открыть меню → Настройки → Назад → закрыть меню. До исправления ход оставался move=1, turn=bot, phase=move, modal=0, scene busy=false. PlanPlayer уже завершён; последним действием authority был cancelBot, без нового scheduleBot. RED: `tmp_files/ux-021/ludo-modal-bot/chromium-red.log`, снимок `chromium-stalled.png`.

Причина: app.openModal отменял presentation и bot timer; возврат в retained меню выходил из closeModal раньше scheduling, а прямое закрытие меню шло через общий registry. Дополнительно scheduleBot запрещал любые модальные поверхности, превращая обычные настройки в случайную паузу.

Исправление общей локальной границы: live table не отменяет presentation/audio/bot при открытии обычной поверхности; input остаётся заблокирован inert и canSelect/canCommit. ScheduleBot не зависит от наличия модального окна; прежние transition/paused/gate/hidden/session/status guards сохранены. Reaction-only refresh может обновлять underlying table и presentation ACK под окном. Явная Пауза, replay, Home и смена session сохраняют собственные lifecycle guards. Данные/правила/authority/PlanPlayer не изменены.

Проверка: существующий `case/ludo-team-markers-browser --name 'Ludo local bot resumes after menu settings and appearance interrupt a dice presentation'`; Chromium 1/1 и WebKit 1/1, exit 0, native Supabase=0, errors=[]. Реальный локальный bot move происходит, пока Settings ещё открыты; app.inert=true; сохранён тот же settings frame. После возврата бот заканчивает ход; явная Пауза удерживает revision. Home → Параметры → Оформление → Назад → сохранённая партия → Продолжить возвращает тот же session/revision без повторного commit. Fixture начального legal state подготовлена до запуска партии; все дальнейшие ходы выполняет штатный scheduler. Это не доказательство физического iPhone/Android и не отдельная проверка окна обвинения UNO.

Логи: `tmp_files/ux-021/ludo-modal-bot/{chromium,webkit}-live.log`. Отчёты и SHA: `final-manifest.json` в том же каталоге. Проверка ограничена этим case; сборка и публикация не выполнялись.
