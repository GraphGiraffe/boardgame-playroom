## Браузерная приёмка окончательного renderer

При проверке найден дополнительный дефект общего Стола: режим ожидания использовал отдельную отрисовку кубиков и менял иерархию controls. Общая функция теперь обслуживает live/inert варианты с теми же региональными ключами; `.yatzy-public-controls { display: contents }` сохраняет владельца узлов без дополнительной видимой панели. В режиме ожидания кубики остаются disabled. Это не право на действие и не изменение правил.

Проверка `Yatzy confirms category and zero score before player or public Table submission` прошла 1/1 в Chromium и WebKit. Она проверяет обе поверхности, отмену, устаревшую revision, нулевой результат, единственную отправку команды и сохранение четырёх незатронутых control/SVG при host hold. Старое ожидание «0 очков» в `.lead` актуализировано: число находится в h2, пояснение «Это завершит ход.» отдельно; проверяются оба текста. Новая проверка удержания сначала воспроизвела замену всех четырёх узлов на общем Столе, после унификации renderer и иерархии прошла.

Сценарий `Yatzy keeps score rows and table scroll stable when dice are held`: 1/1 Chromium и 1/1 WebKit на окончательных исходниках. ## Регионы таблицы и сохранение прокрутки

Категории счёта, заголовок, промежуточные суммы/бонус и итог теперь имеют самостоятельные регионы. Зависимости включают разрешённые команды, содержимое строки, выделенного игрока и подписи. Удержание оставляет содержимое таблицы прежним; запись результата проверена на точное равенство обычной и региональной отрисовки, включая смену текущего игрока и прав. Case/views 27/27 PASS (`yatzy-score-chromium-views-1104.log`). Браузерная проверка подтверждения теперь дополнительно сохраняет все TR при hold: Chromium/WebKit по1/1 (`yatzy-score-{chromium,webkit}-network-feedback-browser-1104.log`).

На WebKit при втором броске выявился сброс прокрутки; отдельный повтор воспроизвёл его. Общий GameScreen раньше сохранял scroll state только без прежнего authored tree. Теперь существующие scrollports сохраняют scrollTop/Left также при обычном и быстром региональном patch; восстановление относится только к всё ещё подключённым узлам и не выполняет повторный layout сцены. Чтение/восстановление координат — отдельная цена; ускорение кадра этим не доказано.

После исправления живой бросок/hold/повторный бросок и сохранение таблицы: WebKit1/1 (`yatzy-score-webkit-scroll-restored-1104.log`), Chromium1/1 (`yatzy-scroll-guard-2-chromium-1104.log`). Общие случаи `scene fragment patches parse only changed regions and retain live input scroll and effects` и `ordinary game patches measure only affected regions and retire private geometry across audiences`: по1/1 в обоих движках, логи guard0/1/3/4. Проверены сохранение ввода/эффектов, адресные замеры и retirement приватной геометрии; это не все игровые поверхности. Оба diff --check: exit0.
