## P0 — единая архитектура и композиция корневых экранов

Сейчас Общение помещает заголовок в верхнюю строку рядом со знаком, Профиль имеет
отдельный h1 ниже бренда, а Мои партии сохраняют двухстрочный hero «Истории игр».
При переключении вкладок прыгает смысловой верх экрана и меняется плотность.

**Предложение для согласования с ведущим:** Общение, Мои партии и Профиль используют
одну корневую шапку с названием раздела и одинаковый начальный отступ содержимого.
Каталог сохраняет утверждённый бренд и hero как осмысленный отдельный случай.
Нижняя навигация не меняет высоту/положение между разделами.

Критерии приёмки:
- каждый корневой раздел имеет один основной заголовок;
- общая шапка и первая строка контента Общения/партий/профиля выровнены между собой;
- отсутствует повтор названия раздела в brand-row и отдельном hero;
- активный раздел понятен по подписи/состоянию, а не только оттенку;
- в 360/390/430 portrait и 844 landscape контент не обрезается нижней навигацией.

## P0 — Мои партии: активные действия раньше служебной истории

Свежий PNG показывает старую информационную структуру: hero, описание, фильтры
транспорта только иконками, счётчик, удаление, затем большая пустая карточка.
Согласованный прототип предлагает вкладки «Активные / История».

UX-критику передано уточнение состава списков; дизайн должен подчиняться ему.
Активная партия/комната — компактная читаемая строка с игрой, состоянием и понятным
действием возврата. История — отдельная вкладка. Экспорт/очистка не занимают
равнозначное место рядом с главным заголовком.

Критерии: в пустом разделе достаточно короткого пояснения и одного «Выбрать игру»;
в заполненном первый экран показывает действующие комнаты/партии; способ связи
передаётся вторичной подписью, а не конкурирующей панелью больших иконок.
Красный/опасный акцент появляется у конкретного опасного действия/подтверждения.

## P0 — лобби: люди и готовность вместо панели инструментов

В источнике ещё присутствуют три группы bot-level icon buttons, смена режимов,
правила/редактирование/смена игры, зрители/Стол и много действий в footer.
Для нового пользователя все группы выглядят равноправными, хотя главный вопрос —
«кто участвует и что мешает началу».

Следующий перенос должен собрать лобби в иерархию:
1. Название комнаты и статус подключения; основные режимы подписаны.
2. Выбранная игра с отдельными понятными «Правила» и «Настроить правила».
3. Участники; тап по человеку открывает единое окно участника. Там же передача
   хоста/исключение, включая зрителя и Стол, при разрешённых состоянием правах.
4. Вторичные зрители/Стол, компактнее основных игроков.
5. Закреплённое главное действие с текстом готовности и понятной причиной ожидания.

Критерии: отдельной панели управления игроками нет; bot-level меняется через
участника-бота/общую осмысленную настройку, а не тремя загадочными значками;
приглашение вызывается из лобби; опасное закрытие не стоит вплотную к готовности;
при длинных именах, четырёх/восьми участниках и landscape прокручивается содержимое,
а главное действие остаётся доступным. Предложение передачи и ответ появляются
поверх текущего экрана; набор кнопок участника известен до открытия окна.

## P1 — Профиль и Общение: личность, затем действия

В профиле имя и статус сейчас отдельные тексты, вход/редактирование — ещё одна
строка. Предложение: единый identity-блок с существующим аватаром, именем, статусом
и очевидной возможностью открыть аккаунт. Ниже спокойные текстовые строки.
Нужны отдельные прогоны гостя и вошедшего пользователя.

Гостевой экран Общения показывает cloud-icon без подписи. Заменить на понятный
подписанный вход в аккаунт с коротким объяснением пользы; сами «Друзья / Чаты»
оставить понятными вкладками. Не вводить новый рисунок иконок.

Критерии: одинаковый компонент личности в собственном профиле и окнах участников;
действие входа понятно без угадывания cloud-icon; строки переходов имеют chevron,
переключатель темы — состояние переключения; основной аккаунтный CTA один.

## P1 — единый визуальный словарь всех поверхностей

Принять три основных вида управления и применять по смыслу:
- текстовая строка + вторичное описание/chevron для переходов и открытия раздела;
- компактная иконка с понятным контекстом для инструмента, зона нажатия от 44 px;
- залитая кнопка для главного действия текущего шага.

Режим/вкладка показывают выбранное состояние, настройка — текущее значение,
опасное действие — отдельный акцент и подтверждение. Панель контекстного выбора
не заменяет полноценный экран настроек, уведомление не перестраивает основную сцену.
Сохраняются старая палитра (бежевый/чёрный фон), арты, stroke-стиль иконок.
Не добавлять декоративные рамки/подложки к каждой строке. Иконки обозначают действие:
stop — остановка, crown-arrow — передача хоста, chevron — переход.
