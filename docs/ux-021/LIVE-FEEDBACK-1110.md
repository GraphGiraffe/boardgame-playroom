## Исправлено

- Catalog/pack HTTP: общий Web-порт `request-deadline.js` ограничивает ожидание без сетевого прогресса8секундами, отменяет fetch/reader и не устанавливает частичные bytes. При получении chunks срок продлевается; лимиты256KiB каталога/4MiB пака проверяются во время чтения. Ошибка освобождает повтор. Флаг navigator.onLine не считается доказательством отсутствия связи через VPN.
- Проверка приложения ограничена тем же бюджетом, включая HEAD и ожидающий native registration.update. Состояние проверки возвращает кнопку в доступное состояние. Нет изменения сетевого игрового протокола.
- История: переход к прошлому кадру очищал кеш проекции. При возврате чтение успевало закешировать пустые действия paused-host; unpause менял controlRevision без игрового move, а локальный subscriber учитывал только reactionRevision. Теперь control-событие инвалидирует legal-cache и обновляет разрешённые действия. Отмена/подтверждение планирования восстанавливаются общим механизмом, без ветки Mage в движке.
- Иллюстрации правил: host получает естественный размер из корневого SVG viewBox и ограничивает диаграммы/stacked controls этим размером и доступной шириной/высотой224px. Изображение уменьшается с сохранением пропорций; на широком экране не растёт до100% контейнера. Невекторные компоненты и авторский SVG не переписываются. Паки .39 не менялись.
