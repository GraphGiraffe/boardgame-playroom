## Ошибки инфраструктуры и границы

Chrome сначала успешно выполнил loot/effects с локального file://. WebKit дважды остановился при навигации с internal error: file:// и локальный HTTP в offline-контексте. Эти попытки не PASS и не доказательство дефекта правил/эффектов. Рабочая альтернатива: стабильный HTTP origin, перехват ровно заданного готового HTML и блокировка всех остальных запросов вместо offline-контекста. Оба случая WebKit прошли; Chrome повторён на окончательном HTTP-пути с теми же assertions. Причина внутренней ошибки движка ниже этого уровня не установлена.

Изменён только существующий `tests/mage-brawl-browser.test.cjs`: отдельный каталог evidence, опциональное открытие точного локального артефакта через HTTP и проверка response SHA. Ветки правил, рендереров и игровые assertions не исправлялись и не ослаблялись. Исторический RED содержал старый формат entity identity и неверный ожидаемый кадр; сейчас он не воспроизводится, но момент и единственная причина его прежнего устранения этим прогоном не установлены.

Не проверены: физическая слышимость и запуск WebAudio (здесь mock audio), DnD и все возможные действия, реальная сеть/несколько устройств, слабый телефон/INP/FPS, все варианты и все стечения правил. Данные rotation-timings относятся к инструментированному fixture и не заменяют измерение производительности приложения. Полная authored-разметка и остаточная задержка около100мс остаются открытыми; цель0.21 остаётся work.
