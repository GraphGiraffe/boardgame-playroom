# Компактные параметры: preview.66 / коллекция preview.40

Предыдущий интерфейс preview.65 был переработан после обратной связи владельца. Это подготовка тестовой версии, не стабильный выпуск.

## Поведение

Три группы следуют порядку «Порядок игры» → «Параметры» → «Завершение». Обычные карточки располагаются компактной сеткой, показывают одну изменяемую иллюстрацию, текущее значение и авторское описание. Четыре значения — 2×2; подписи опций однострочные, длинная кнопка переносится целиком. Разрешён максимум один крупный блок, только для явно существенно отличающихся режимов. UNO5/7 — обычная карточка количества.

Тап по свободной области карточки или кнопке preview переключает вариант по кругу. Тап по опции выбирает точное значение. Help, прокрутка, другие контролы и readonly не переключают вариант. Клавиатура и фокус сохраняются при обновлении. Изменения остаются черновиком до Save; Cancel, смена комнаты/владельца и rulesRevision сохраняют прежние ограничения.

Open hands удалены из редактора, кратких параметров и конфигурации справки. Новая локальная и hosted-сессия принудительно использует false после слияния опций. Исторические восстановленные сессии и их проекции не переписываются.

## Метаданные и инструменты

Опциональные preview-подсказки ограничены схемой компилятора и импортера: безопасный набор компонентов/символов, численные пределы и ссылки только на известные значения полей. Они не добавляют game-ID ветвления в общий редактор. Паковые правила и engineApi4/viewApi3/protocol3 не менялись. Канонический компилятор находится в коллекции; host-копия и digest синхронизированы.

Девять обновлений: UNO.18, Mage.26, Ludo.13, Battle.13, GoFish.12, Durak.14, OldMaid.12, Klondike.14, Snakes.11. OldMaid36/52 означает тип колоды, реальная иллюстрация35/51 учитывает удалённую даму. Yatzy всегда использует5кубиков: число раундов не рисуется как число кубиков.

Dev-плагины0.4.5 добавляют read-only план смартфонных проверок и инспектор публичных parameter hints; canonical implementation и provenance принадлежат utils. Они не запускают тесты/публикации автоматически и не заменяют проверки правил. Подробности — canonical utils docs/PHONE-INTERACTIONS.md.

## Проверки и границы

Исходники:25 сценариев редактора (24 успешных неизменённых +1 исправленный focused fixture), независимые native taps/Enter/help/scroll/readonly и большой системный шрифт32px. Найденное переполнение Battle/Ludo исправлено и повторено2/2. Проверены26 полных описаний в4состояниях без CSS-clipping. Domain-contract проверяет реальные исходные количества, команды и флоты; отдельный HostSessionService тест подтверждает новые скрытые руки и сохранение исторического режима.

Финальная сборка, SHA/ZIP, проверки точного автономного HTML и опубликованных байтов фиксируются отдельно в tmp_files/compact-parameters-1110. Успешные gameplay-проверки15паков и первых ходов из preview.65 повторно используются только для неизменённых игровых модулей. Это Chromium/WebKit эмуляция, не физический Samsung, не новая Online/max-clients приёмка и не accessibility-screen-reader acceptance.

Референс композиции/взаимодействия: https://hudobistro.ru/ и видео владельца. Touch targets остаются проектными44px, не копируют мелкие32px кнопки референса. Primary practice: https://web.dev/learn/design/touch и https://web.dev/learn/design/typography — reflow, доступные цели и читаемый текст. Увеличенный шрифт даёт естественную прокрутку единственного body панели; текст не обрезается ради высоты экрана.
