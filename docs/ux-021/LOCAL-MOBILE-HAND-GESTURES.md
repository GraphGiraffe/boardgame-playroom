Причины: core/input touch timer напрямую вызывал beginDrag→select; previewDown также поднимал карту на touch-down. Blank clicks без button не попадали в host input.handleClick. Suppression остаётся привязан к отменённому pointer до его настоящего up/cancel, затем работает обычное ограниченное compatibility-click окно; новый pointerdown сбрасывает его, keyboardclick не блокируется. Measured-origin ghost fix не изменён; rules/authority/privacy не изменены.
