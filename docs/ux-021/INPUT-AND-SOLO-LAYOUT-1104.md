## Изменения

- Пасьянсы с объявленным `data-solo-field` используют одноколоночную раскладку без пустых зон игроков. Объявленные `header-landscape` действия действительно размещаются в заголовке. При повороте сохраняются игровые узлы и их принадлежность.
- Заголовок учитывает фактическую ширину статистики и кнопок. При нехватке места действия занимают второй ряд, сохраняя размер текста и область нажатия. Обычный ход сохраняет ряд; полный пересчёт сцены для этого не вызывается.
- Меню истории предлагает «Вернуться к истории». Недоступная в истории пауза получает причину, если другая причина ещё не задана.
- Возврат из списка обучения восстанавливает существующую форму настроек, её прокрутку и фокус.

Нативная проверка обнаружила настоящий дефект: скрытая внешняя сцена пасьянса имела переполнение, а автоматическая прокрутка Playwright при клике маскировала недоступность колоды. Исправление проверено без такой прокрутки. Это не устанавливает причину всех ранее снятых на телефоне ошибок жестов.

## Исправление доказательства проверки

Первые четыре запуска с заданным `PLAYROOM_SOLO_ARTIFACT` ошибочно перехватывали URL с двойным слэшем. Они подтверждали исходную страницу, а не скомпилированный HTML. Эти попытки сохранены отдельно и исключены из приёмки артефакта. Исправленный существующий opt-in case сравнивает SHA фактического navigation response с SHA файла. Все пять результатов в `artifact-verified` содержат совпадающий `servedSha256`. Старый root-context runner открывает сам файл напрямую; его путь не затронут этой ошибкой.

Первая попытка обновить source ZIP выбрала общий dist с архивными несовместимыми паками и завершилась ошибкой viewApi. Повтор использует canonical `playroom-paks/packs`; сборка успешна, HTML/cache неизменны. Ошибка не считается успешной проверкой.
