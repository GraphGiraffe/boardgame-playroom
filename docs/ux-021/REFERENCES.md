## Вывод

Главная проблема не решается уменьшением всех кнопок. Нужно уменьшить число
одновременно предлагаемых решений, вернуть подписи и разделить цель пользователя
и техническую реализацию. Размер цели касания сохраняется, поля и вложенность сокращаются.

## До и после: проектируемые пути

| Задача | Наблюдаемая проблема | Целевой путь (ещё не замерен) |
|---|---|---|
| Войти к другу | Непонятная Wi-Fi иконка рядом с онлайн | Войти в комнату → номер/приглашение → вход |
| Пригласить | Иконки и настройки смешаны | Лобби → Пригласить → друг/группа/ссылка |
| Написать в партии | Уход из контекста и лишние возвраты | Чат → сообщение → закрыть sheet |
| Настроить звук | Много разных функций на одном экране | Профиль → Настройки → Звук |
| Изменить масштаб | Пользователь исправляет компоновку вручную | Ноль действий: адаптация автоматически |
| Рассадка трёх соперников | Параметр требует знания геометрии | Ноль действий: доступная площадь определяет размещение |
