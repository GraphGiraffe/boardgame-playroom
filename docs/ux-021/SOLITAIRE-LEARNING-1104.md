# Проверка всех целей обучения пасьянсов — 4 ноября 2026

Статус: на точном ранее опубликованном HTML b3f3c8 проверены все 13 целей: Spider 5/5 и Klondike 8/8. Это подтверждение перечисленных целей в выбранных вариантах и позициях, не полная игровая, физическая или usability-приёмка.

## Сценарий

В существующий rc2-presentation-browser добавлен случай `solitaire learning masters every goal through real input and validated saved positions`.

Используется настоящая app/session/save-library/input/tutorial цепочка. Позиции проходят E.validateState и TabletopSession.restore, затем открываются через Мои партии → действия сохранения → Продолжить. Никакие mastery-флаги вручную не записываются; в начале обеих игр mastered пуст. Обычные source/target, hint и undo выполняются настоящими keyboard/click действиями. Редкие flip/collect/recycle проверены на валидированной заранее подготовленной позиции Klondike со всеми 52 уникальными физическими картами.

Опции: seed 17, undo:history, для Klondike autoFlip:manual и autoCollect:button. Поэтому результат **не доказывает прохождение всех целей в настройках по умолчанию** или одну естественную партию от раздачи до победы. Progress принадлежит тестовому профилю rc2, контекст браузера изолирован от пользовательского.

- Spider: выбран источник → подсказка цели → перенос → раздача → отмена → подсказка возможного хода. Hint не увеличивает номер игрового действия.
- Klondike: перенос → открытие stock → ручной flip → двойной клик по свободному полю и настоящий collect → undo → hint → реальные доборы до пустого stock → recycle.
- Каждый command проверен как ровно один следующий move; локальный hint отдельно от command. Для всех целей проверяется показ соответствующей подсказки, а не только наличие tutorial.js.
- Через Меню партии → Настройки → Поведение → Действия обучения показаны 5/8 checked disabled пунктов и «Все действия освоены». Один Back возвращает в настройки, следующий — в игру.
- После reload все goal revisions сохранены у обеих игр, завершённое обучение не запускается повторно.

## Обнаруженное ограничение и исправленные ожидания теста

Первоначальный CSS-селектор нового теста содержал синтаксическую ошибку; исправлен до выполнения сценария. Затем в портретном Spider ожидаемая цель была x459, за правым краем viewport390. Подсказка в этом состоянии выбирает видимый stock вместо невидимой цели. Выделение карты и допустимая цель сохранялись; это не зависание правил. После реального горизонтального wheel-жеста к цели подсказка переноса появилась и ход выполнен. Сценарий учитывает прокрутку; проверка подсказки не удалена.

**Открытый usability-вопрос:** обучение не объясняет горизонтальную прокрутку к выбранной цели и может советовать добор вместо завершения переноса. Полная самостоятельная проходимость без подсказок автора этим не принята. Default undo:last и autoFlip:auto требуют отдельной проверки достижимости/порядка целей; здесь использованы явно названные варианты.
