# Стандартные правила пасьянсов и обучение — 4 ноября 2026

Статус: добавлена и выполнена адресная проверка стандартных вариантов Spider/Klondike. Runtime и опубликованное превью не менялись. Полная GOAL 0.21 остаётся открытой.

## Проверенный путь

Новый сценарий `default solitaire rules preserve actionable guides and single-step undo` использует тот же настоящий Session/save-library/UI-путь, что и [предыдущая проверка всех целей](SOLITAIRE-LEARNING-1104.md), но не задаёт `undo`, `autoFlip`, `autoCollect` или `draw`. Проверяются действующие defaults: undo:last, а для Klondike — autoFlip:true и draw:3. Оба варианта используют seed17; Klondike получает валидированную расстановку физических карт из исходной колоды, чтобы явно проверить раскрытие карты и сбор. Это не случайный полный матч и не независимый первый запуск новым человеком.

Позиции валидируются моделью, восстанавливаются через Session.restore, сохраняются и открываются из «Моих партий». Выбор карты идёт через настоящий фокус/Enter, перенос — через разрешённую цель. При скрытой цели проверяется подсказка направления, отсутствие автоматического scroll/mastery и последующая ручная прокрутка.

Spider: выбор/перенос → доступная кнопка Undo до раздачи → раздача → подсказка. После единственной отмены второй Undo отсутствует. После раздачи Undo также отсутствует: раздача является границей отмены при стандартных правилах. Освоены5/5целей. Undo в этом сценарии нажимается по доступной кнопке, без требования, чтобы текущий указатель обучения уже советовал его; самостоятельная обнаружимость всех действий человеком этим не доказана.

Klondike: выбор/перенос → добор3карт → сбор двойным нажатием → Undo → подсказка → добор до опустошения → возврат сброса. После переноса закрытая карта раскрыта автоматически, отдельной команды flip нет, её mastery не присваивается. Семь доступных целей освоены, в общем игровом списке ручной flip остаётся единственным неотмеченным. Нет ложного сообщения «Все действия освоены». Неосвоенный, но неприменимый к текущему варианту flip не удерживает видимую подсказку и не блокирует продолжение.

Список обучения сейчас является общим списком возможностей игры, а не фильтруется по варианту правил. Эта проверка фиксирует фактическое поведение и не объявляет ручной переворот освоенным автоматически. Отдельная маркировка применимости целей к варианту здесь не реализована.

Через настоящее меню проверены чек-листы, один Back к настройкам и следующий Back к игре; reload сохраняет ревизии освоенных действий. После reload навязчивая подсказка не появляется заново. Hint не создаёт ход. Каждая ожидаемая игровая команда повышает move ровно на1; сцена выходит из busy.

## Остаётся

Пробел стандартных правил сужен до указанного сценария, а не закрыт для любых раскладов и настроек. Не проверены полный выигрыш/проигрыш, все варианты suits/scoring/maxPasses, физические touch/звук, продолжительные задержки/фон, независимая usability и AT. Ручной flip в текущем default-матче не является доступным действием; его достижимость отдельно подтверждена ручным вариантом. Перечисленные ограничения не переносятся автоматически в будущий SDK и не завершают общую приёмку0.21.
