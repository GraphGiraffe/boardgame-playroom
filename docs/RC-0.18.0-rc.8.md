# 0.18.0-rc.8 — общая геометрия и приёмка

## Решения по замечаниям владельца

| Повторяющаяся проблема | Общее решение | Где проверять |
| --- | --- | --- |
| Круг сжимает поле, боковые руки обрезаются | Только углы/ряд; прежний выбор circle отображается как углы. Дуэли и Ятзи — ряд. Fallback по фактическому пересечению зон, без записи предпочтения | Все 12 игр, максимальный состав, телефон/планшет, обе ориентации |
| Растянутые панели Акулины/Рыбы/Дурака, огромная рука | Удалён растягивающий приоритет hands. Общая компактная метаинформация, высота по содержимому, единый размер своей руки | 2–6 игроков, скрытая/открытая/пустая рука |
| Landscape теряет высоту из-за верхних полос | Название/основной статус слева, команды/ход справа; центр занимает полную высоту | Поля, доступные действия, история |
| Пексесо меняет сетку при ходе и летит из-под игроков | Конечная область сетки и подбор столбцов по ширине/высоте; flip не участвует в перелёте карты из руки | Повторные совпадения/несовпадения, стабильность и непрозрачность обеих сторон |
| Слишком много карт Пексесо | Для новых партий 8/12/18 пар; полный режим убран из предложения | Все три режима, персонажи/игральная колода |
| Долгая пауза внутри хода, короткий результат кубиков | Отдельный diceReveal; без card-budget после броска и продолжения того же timeline.turn | Ятзи, Лудо, двойное взятие шашек, локально/сеть/история |
| Толстые обрезанные рамки | Общая рамка 2px с меньшим отступом; круглая фигура ближе к рамке; шашки выше соседних клеток, без заливки цели | Край доски/руки, selected/focus/drag, светлая/тёмная |
| Морской бой: маленькое поле | Новая общая landscape-сцена, корабли сбоку столбцом | Расстановка, бой, просмотр своего/чужого флота |
| Домино: чрезмерный крупный показ и нижний артефакт | Сохранены 4:7, ограничен размер показа; удалена дублирующая внешняя тень | Свой ход, бот, перенос на цепочку |
| Змеи: белая обводка | Удалён лишний светлый путь, сохранены цвет и форма | Поле в обеих темах |
| Темы из настроек не открываются | Удалена блокировка editor вне app-shell; native dialog поверх настроек | Открытие/закрытие, возврат фокуса, отсутствие изменения партии |
| Аватар не выровнен с именем | Общая высота 48px для поля и квадратной кнопки; выравнивание по полю | Приветствие, настройки, никнейм комнаты |
| Меню/уведомления | Компактный верхний toast без наследованного bottom; единый поток участников без командных строк | Прокрученное меню, настройки, последние партии |

| Недавние завершённые партии | Локальную скрывать; сетевую сохранять только при действующем подключении. Незавершённую сетевую показывать независимо от связи. Архив не удаляется | Все комбинации завершения/подключения |
