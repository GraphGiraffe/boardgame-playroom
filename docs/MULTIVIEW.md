## Стол

**Стол — это Зритель, на котором игроки могут совершать публичные действия.** Видимость данных одинакова; право выполнить действие проверяется отдельно. Выбор surface не выдаёт права игрока.

- Поле, фишки, кубики, публичные перемещения и события видны на Столе.
- Руки присутствуют как у Зрителя: рубашки/количество при закрытых руках, лица при общем режиме открытых рук. Собственной приватной руки у Стола нет.
- В Морском бое во время партии обе расстановки скрыты, видны публичные выстрелы и их результаты. Открытые руки карточных игр не открывают корабли. Завершённая партия следует существующей политике раскрытия пака.
- Публичный ход можно выполнить со своего устройства или на Столе. Выбор закрытой карты и приватная расстановка выполняются с личного устройства.
- Публичность должна включать доступность и аргументы команды **до её выполнения**. Публичный результат не делает приватный выбор публичным: например, список номиналов в руке нельзя передавать Столу для запроса карты.
- Архив и повтор не предоставляют управление. Обычный Зритель остаётся read-only.

## Реализация и границы текущего среза

`GameModel.projectTable(position, actor)` берёт данные/события из зрительской проекции, сохраняет viewer=-1 и добавляет только команды с явным visibility='public'. `commandFor(..., 'table')` повторно проверяет доступность. Временный адаптер предоставляет `TabletopCore.projectTable/applyTableAction`; вызывающий application controller обязан проверить право использовать actor. Эти функции сами не аутентифицируют соединение.

Крестики-нолики engineApi 3 объявляют публичную постановку знака. Неперенесённые паки не получают управления Стола автоматически. В текущем сетевом протоколе соединение Зрителя по-прежнему read-only; роль Стола, привязка разрешённых акторов, маршрутизация команд и безопасные history/receipts будут подключены этапом authority/controller. Это фундамент контракта, не готовая сетевая функция для всех игр.

Пак регистрирует render и при необходимости surfaces.table/player. Рендерер возвращает api:2, family, playerContent и elements; GameScreen размещает их. Player descriptors индексированы исходными playerIndex. Личные hand controls исключаются со Стола; публичные controls передаются только из разрешённой проекции. Удаление кнопки не заменяет фильтрацию данных.

SessionAuthority выдаёт snapshots/history для закреплённого viewer. SharedViews использует GameScreen/Input; архивный просмотр не dispatch-ит команды. Live effects, replay и результаты различаются; итог партии сохраняется при выборе начального кадра. Production authority работает в браузере хоста.
