# RC16 — компактный интерфейс и прокрутка руки

Приложение 0.15.0-rc.16, коллекция 0.4.0-preview.8, Шашки 0.3.2. Остальные паки сохраняют версии RC15. Stable и развёртывание сайта в этап не входят.

## Исправления

- `PlayroomGameScreen.deleteConfirmation({name, network, confirmAttrs})` задаёт общую разметку, заголовок, пояснение и кнопки удаления. Приложение передаёт только собственные атрибуты маршрутизации. Сетевое окно уточняет локальность удаления; обработчики и состав данных не изменены.
- В общем вводе распознавание прокрутки отделено от разрешения игрового действия. Старт жеста разрешён на любом элементе или пустом участке прокручиваемой руки; действие по-прежнему требует доступности и прав. Для нейтрального жеста нет таймера перетаскивания и игрового свайпа. Сохраняются пороги 7 px и преобладание оси 1.1, подавление клика после скролла и блокировка фона модального окна.
- При наличии общего объекта `shared` и отсутствии `status` список участников занимает обе верхние строки левой колонки. Высота кубика справа больше не создаёт пустую область над соперниками. Список имеет собственную прокрутку.
- Общий `playerContent.counters` допускает до трёх уникальных видов: `points`, `wins`, `pieces`. Новый вид `pieces` отображает только неотрицательное целое число в круге; `label` используется в aria-label/title (по умолчанию «Фишки»). Старые виды и значения по умолчанию сохранены.
- Шашки передают `wins` и `pieces`; сторона указана в доступном названии счётчика, видимые текстовые badges/colorLabel не используются. Счётчик отражает фигуры текущего состояния, включая историю; цвета аватарок сохранены.

Форматы сетевых команд и сохранений не меняются. Старые опубликованные паки не перезаписываются.
