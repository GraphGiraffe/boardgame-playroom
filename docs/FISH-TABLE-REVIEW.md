# Рыба: согласованная плотность таблицы, RC23

Только рассадка в ряд; сохранённая рассадка по углам игнорируется, переключатель рассадки скрыт. Карты номиналов 24 px, аватары 24×24 px, номинал в левом верхнем углу, единый шаг перекрытия 14 px для всех мини-карточек, «10» сдвинуто примерно на 1 px влево; следующая карточка может закрывать часть нуля. В каждой строке сохраняется одна прокручиваемая ячейка сетов с выравниванием слева. Общий адаптер выбирает один или два столбца по доступной ширине/высоте области поля; порога числа игроков нет.

Искусственная проверка: 3–6 игроков, у каждого все 13 сетов; 320×640, 390×844, 844×390. Проверяются сохранение размеров поля/таблицы при заполнении, центрирование аватаров, размер карт, очередность и достижимость последних сетов прокруткой.

Пользователь подтвердил скриншоты и разрешил выпуск нового RC 2026-10-18. Опубликованные RC22/коллекция RC16 остаются неизменными; версия исходников Рыбы rc9, коллекции rc17 зарезервирована для следующего выпуска.

Общее правило приложения: мини-руки всех паков/рассадок/поверхностей обрезаются по высоте; размер полной карты или костяшки сохраняется. Собственная рука и модальный выбор карты не обрезаются. Публикация RC23 разрешена, production не переключается.

Проверено: профильная матрица presentation (55 сценариев) и network feedback (10) прошли; отдельная проверка перекрытия/обрезки — 4/4, включая пять игр с руками, обе рассадки, combined/table/player и открытые/скрытые руки. Снимки телефона просмотрены.

Дополнительная старая game-layout-browser матрица не пройдена: текущий расширенный прогон 186 pass / 59 fail; исходный RC22 d786da5 в изолированном checkout — 115 pass / 65 fail (включая вложенные сценарии). Совпадают прежние проблемы ожиданий собственной копии активного игрока, геометрии повёрнутых счётчиков, компактных кнопок и отдельных очень низких экранов. Порог кнопок и проверка числа активных панелей не изменены: автоматическая проверка отклонила предложенное изменение как возможное ослабление. Эту матрицу нельзя считать зелёной или скрывать при подготовке выпуска; Для RC23 выбран адресный gate по изменённому поведению; старую матрицу сохраняем без ослабления требований и отдельно отмечаем как прежнее ограничение, её зелёный статус не заявляется.

Последнее уточнение «10»: общий шаг всех мини-карточек 14 px; номинал «10» смещён примерно на 1 px влево, следующая карточка может закрывать часть нуля. Остальные буквы/цифры полностью видны. Целевые проверки этой правки: 4/4, скриншоты портрета и landscape обновлены. Пользователь подтвердил этот вариант.

Объём мини-карточек: скругление 3 px, торец 1 px в цвете боковой поверхности обычных карт и мягкая тень. Размеры и шаг перекрытия сохранены; визуальный сдвиг вверх на 1 px оставляет место для тени внутри прежней строки высотой 36 px.

Мини-карточки вынесены в shared/asset-packs/mini-cards (0.1.0), общий набор с рендерером и CSS без зависимости от Рыбы. Аватары имеют единое скругление 22% стороны вместо радиусов в пикселях.

Выпускной gate RC23: 117/117 (48 core, 56 presentation, 10 network, 3 appearance). Проверены одинаковые квадратные аватары во всех контекстах и обеих ориентациях; скриншоты просмотрены.
