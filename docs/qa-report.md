# Проверка раздельного релиза 0.13.0 / 0.1.0

Дата: 6 октября 2026 года. Проверки выполняются в Node.js 22, Python и изолированном Chromium. Физический телефон, Safari и Firefox не проверялись.

## Контракт и сборки

- Базовый HTML содержит приложение/движок и ноль игровых паков; дополнительный HTML содержит пять паков. Внешние script/link-ресурсы не требуются.
- В исходном архиве приложения нет исходников игр и generated preload. Распакованный архив самостоятельно собирает идентичный базовый HTML.
- Архив движка содержит все объявленные exports; восемь JavaScript-модулей импортируются без DOM. Браузерные методы по-прежнему требуют браузер при вызове.
- JSON-паки, их коллекция, архивы и SHA256SUMS собираются отдельно. Пакеты не зависят от абсолютных путей рабочего компьютера.

## Сценарии новых возможностей

Установка через настоящий выбор файла и явное подтверждение; предварительный просмотр без исполнения; ошибка JSON/формата/API; повреждённый код; атомарный отказ при нехватке хранилища; защита опубликованной версии от перезаписи; обновление и перезагрузка; точные старые правила, view и CSS у прежней партии; новая версия у новой партии; отсутствующая версия и восстановление без изменения raw-сохранения; запрет удаления используемой версии; удаление встроенной игры не отменяется перезагрузкой.

Runtime-ошибки cover/render/playerBadge локализуются: хаб и менеджер остаются доступны, сломанный пак можно удалить. Конфликт одинакового номера версии сохраняет прежний установленный код и выдаёт предупреждение. Недоступное хранилище позволяет запустить встроенные игры в памяти без попытки затереть данные.

## Область CI

CI приложения собирает базовую поставку, проверяет синтаксис, общие жесты и анимации без доступа к приватному репозиторию игр. CI паков проверяет синтаксис, сборку и SHA256SUMS. Полный совместный прогон правил и интерфейса выполняется локально с двумя checkout; его результат и проверка релизных HTML приведены ниже.

Исторические результаты 0.1–0.12 сохранены в прежних локальных архивах прототипа и не считаются проверкой текущего релиза.
