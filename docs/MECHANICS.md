# Реестр механик · ХОД

Область применения: приложение **0.21.0** и коллекция **0.8.10**, engineApi 4 / viewApi 3 / protocol 3. Исторические этапы ниже поясняют совместимость; текущая приёмка хранится в [utils](https://github.com/GraphGiraffe/boardgame-playroom-utils/blob/main/docs/project/app/reports/ACCEPTANCE-0.21.0.md).

Названия ниже используются в документации и новых задачах. Это смысловые контракты; фактические имена полей SDK указаны рядом.

| Название | Контракт и владелец |
|---|---|
| **Разрешённое действие** | GameModel.actions/reactions возвращают command и visibility. Authority повторно проверяет actor, revision и легальность. |
| **Выбор источника** | H.source / ui.selected: выбор карты, кости или фишки без изменения партии. |
| **Цель хода** | H.boardTarget / H.target: общий click, focus, hover, активное состояние. Занятая своей доступной фишкой клетка прежде выбирает фишку; ход возможен по кубику или свободной части цели. |
| **Предпросмотр маршрута** | H.routeDot и разрешённые цели из presentation; UI не вычисляет правила. |
| **Быстрый ход** | Локальная настройка quickPlay; не обходит выбор обязательного цвета, цели или подтверждения. |
| **Разделение жестов** | core/input различает scroll, select, hold/inspect, drag и swipe. Прокрутка доступна с любой карты; после scroll нет commit. |
| **Фиксированная сцена** | Размеры зон сохраняются на действиях. allowLayoutChange разрешается только конкретному действию; размер окна/viewer/surface и явная настройка создают новую геометрию. |
| **Рука-веер** | Локальный default: дуга; прямая рука доступна для карт, домино всегда прямо. Перекрытие не растягивается до свободной ширины. |
| **Мини-рука** | В карточке игрока: левое выравнивание, перекрытие, обрезанная высота во всех паках и рассадках. |
| **Отложенный эффект** | Публичный badge, общий значок и цвет клетки; расход/срок задаёт domain. Бейджи остаются одной прокручиваемой строкой. |
| **Бросок кубиков** | Анимируется каждый новый roll, кроме instant; прежние грани сохраняются, до первого броска показаны непустые preview-грани. |
| **Крупный показ хода** | reveal card/cards/dice: вход → удержание → завершение/перелёт; только публичные данные, слой ниже модальных окон. |
| **Передача рубашкой** | transfer не раскрывает лицо скрытой карты. Публичный сброс пары/сета сначала показывает все открытые карты. |
| **Последовательное перемещение** | presentation.sequence: несколько маршрутов одного принятого действия, без дополнительных команд пользователя. |
| **Сигнал действия** | feedback/sound/notice/speech после projection; семантический приоритет cue, отсутствие дублей ACK/reconnect. |
| **Единицы прогресса** | revision — действие, timeline.turn — ход, round — объявленный цикл. Выбор/hold/анимация сами по себе не заканчивают ход. |
| **История проекций** | Разрешённые кадры; received/presented/reviewed раздельны. Просмотр не выдаёт игровые commands; autoplay использует общие эффекты и звук. |
| **Независимая реакция** | Отдельные reaction windows/episode; authority управляет сроком. Повтор завершённого эпизода не создаёт revision. |
| **Подтверждение действия** | confirmation в presentation.choice; Ятзи подтверждает запись комбинации. Отмена не изменяет Session. |
| **Смысловой счётчик** | SceneModel.metrics с ID/kind/value/resultUsage; UI не угадывает тип по подписи. |
| **Первый игрок и очередь** | firstPlayer задаёт начало круга; публичный orderPosition может уточнить порядок. Физические места не прыгают при reverse UNO. |
| **Командный результат** | Result/metrics/places вычисляет domain; общий UI показывает команды, победителей и равенства. |
| **Локальное оформление** | Appearance/AssetResolver выбирают тему и вариант без изменения command/state/RNG. |
| **Безопасный масштаб** | 50–150%, шаг 10%, default 100%; все точки видны, недоступная часть линии серая, значения блокируются. |
| **Скрытая локальная партия** | Удаляет карточку возврата с главной, оставляет сохранение в «Мои партии». |
| **Публичный Стол** | Зрительская проекция + явно выданные права на public actions; приватные команды остаются на личном устройстве. |
| **Надёжная квитанция** | State/journal/receipt фиксируются до ACK; повтор commandId не создаёт второй ход. |
| **Точное сохранение** | packId + packVersion + проверенная история; автоматической подмены правил новой версией нет. |

## Игровые механики коллекции

- **ЗиЛ+** (default): два кубика и выбор одного, дубль даёт дополнительный бросок после хода. Клетки: «Пропуск» (красный), «Поправка ±1» (фиолетовый, выбор в следующем ходе), «Один кубик» (оранжевый, следующий бросок), «Второй кубик» (бирюзовый, автоматическое второе перемещение), «Щит» (синий, автоматически блокирует один отрицательный эффект: змею, пропуск или уменьшение числа кубиков). Поправка обязательна до хода и меняется до commit, применяется только к выбранному кубику. Второй кубик её не повторяет. Клетки дополнительного броска нет. Лестницы/змеи не начинаются на специальных клетках; маршруты поверх клеток, фишки поверх маршрутов. Простой режим использует один кубик.
- **Лудо**: выбор фишки, общие цели/маршруты, выход из базы и взятие по правилам, команды через manifest.teamLayouts. Собственная фишка в цели не превращает нажатие для её выбора в ход другой фишкой.
- **Рыба**: вопрос номинала, скрытая передача, публичный квартет. BookCards сохраняет первую карту сета. Таблица аватаров и перекрывающихся мини-карт номиналов делится по доступной области, имеет только рассадку в ряд.
- **Акулина**: выбор закрытой карты в модальном окне и публичный показ сбрасываемой пары.
- **Пексесо**: случайные цвета/фигуры на новую партию, каждый из восьми персонажей присутствует хотя бы одной парой; одинаковые лица пары, seed воспроизводим. Память бота использует только ранее открытые карты.
- **Ятзи**: до трёх бросков, удержание кубиков, предпросмотр очков, подтверждение записи, крупный показ зачтённых кубиков. До шести игроков.
- **UNO**: выбор цвета, публичные карты, reverse, draw/skip, объявления и независимые реакции; физические места сохраняются.
- **Дурак**: атака/защита/перевод/подкидывание, скрытый добор, явные завершения; роль атакующего принадлежит инициатору.
- **Домино**: выбор костяшки и конца цепочки, скрытый добор, пропуск; собственная рука прямая.
- **Морской бой**: приватная расстановка с переносом/поворотом/снятием, явная готовность, публичный выстрел; скрытые поля защищает projection.
- **Шашки**: разрешённый выбор и маршрут, цепочка взятий, семантические события capture.
- **Крестики-нолики**: первый игрок получает X, легальные клетки и результат определяет domain.

Точные варианты и окончания перечислены в metadata.presets и manifest.settings каждой игры; общая оболочка показывает только применимые настройки и скрывает единственный вариант.

## Передача устройства в хотсите

Настройка автопередачи доступна только во время партии хотсита и выключена по умолчанию. Для основного игрока сохраняется в личных настройках между партиями и лобби. Для остальных привязана к ID участника и ID лобби: сохраняется при новой партии, смене места и перезагрузке в том же лобби; новые участники нового лобби начинают с выключенной опцией. При включённой опции кнопки нет; переход происходит после представления и окна реакции, например UNO. При выключенной опции кнопка постоянно занимает правый нижний угол своей карточки, активируется и мягко пульсирует после хода. При отдельной рассадке с дублированием собственной карточки (Лудо) кнопка располагается в углу игрового экрана. Приватность закрытых рук, пауза, история и модальные окна сохраняют прежние ограничения. Старое общее предпочтение сохраняется только за основным игроком; гости его не наследуют. Изменение одного игрока не меняет других.

Кнопка передачи не увеличивает карточку: максимум 36 px, с уменьшением по её высоте. При отдельной рассадке её контейнер принадлежит оболочке `.scene`, а не заменяемому содержимому пака. Контекстные кнопки общего `actionBar` и резерв строки — от 32 px; элементы поля, кубики и карты этим правилом не уменьшаются.

### Защита независимых реакций

Окна реакции принадлежат и людям, и ботам. Человек подтверждает готовность представления; для бота таймер запускает authority без клиентского ACK. В UNO человек может обвинить через 1 секунду, бот — через 3 секунды после готовности владельца окна. До этого действие имеет презентационный флаг `disabled`, и меню оставляет кнопку видимой, но неактивной; серверная проверка продолжает отклонять преждевременные команды. По истечении срока authority публикует изменение доступности без игрового хода. Собственное объявление остаётся доступным; ожидающее обвинение не блокирует запланированный ответ другого бота.
