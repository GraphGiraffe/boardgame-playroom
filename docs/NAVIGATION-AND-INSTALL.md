# Навигация и установка

Контракт 0.18.4. Системная кнопка Назад закрывает верхнее окно; из локального лобби возвращает на Все игры, из сетевого — после подтверждения. Из Моих партий возвращает на Все игры. В партии системный Назад требует подтверждения, явная кнопка приложения выходит сразу.

На главном экране обычный браузер (включая offline HTML) выходит без диалога и без промежуточного экрана. Только display-mode: standalone / navigator.standalone включает подтверждение выхода PWA. Браузер управляет фактическим закрытием; приёмка на установленной Android PWA остаётся отдельной проверкой. До первого взаимодействия браузер может пропускать записи истории.

Установка доступна только после beforeinstallprompt и вызывает его prompt/userChoice; appinstalled или потреблённое приглашение убирает кнопку. Тестовые глобальные флаги и фиктивная установка в релиз не входят. Пульс меняет только фон, не размеры/фильтр/тень/иконку; при reduced motion выключен. Возврат из окон снова запускает пульс.

В темах равные зоны темы и аватаров. Общие действия окон закрепляются, но действия отдельного поля/способа (никнейм, ответ на приглашение) остаются внутри соответствующего блока. Сброс настроек, правил и скинов подтверждается собственным диалогом. Справка прокручивается отдельно от нижнего действия.
