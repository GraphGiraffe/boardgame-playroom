# ХОД 0.15 · стабильный выпуск

Приложение **0.15.0**, коллекция игр **0.4.0**. Стабилизация общей игровой сцены, локальных и сетевых комнат, сохранений и мобильного управления. Версии отдельных игр не меняются при переводе коллекции из preview в stable.

## Возможности и исправления

- Одна комната для локальной игры, Hotseat и сети; места, боты, зрители, общий Стол, готовность, правила и выбор первого игрока. Понятное приглашение `👤+` в лобби и игре, компактный переключатель «Локальная / Сетевая».
- Браузер хоста выполняет правила; WebRTC передаёт разрешённые проекции. QR, Share, текст и звук помогают обменяться приглашением и ответом. Звуковой модуль ожидает готовности при первом запуске.
- Хостовый IndexedDB-журнал сохраняет состояние, историю и квитанции до подтверждения команды. Исправлены обработка ожидающих команд, реакции вне очереди и блокировка клиентского хода после обновления.
- «Остановить и сохранить» сохраняет матч и возвращает участников в прежнее лобби с настройками. Продолжение сохранения восстанавливает состояние и проверяет права на места; возвращение из меню не останавливает игру.
- «Мои партии» объединяет локальные и сетевые записи; игроки с данного устройства выделены жирным. Удаление использует единый диалог. Главная показывает общие карточки продолжения, выхода и переподключения.
- История использует компактные руки и воспроизведение анимаций. Результаты остаются открыты у клиента, пока он сам не вернётся в комнату. После завершения кнопка кубка занимает место кнопки лобби, включая просмотр ранних кадров истории.
- Окна ограничивают свои анимационные слои и прокрутку; содержимое не просвечивает над шапкой. Обновление лобби сохраняет прокрутку. Drag-and-drop ограничен местами, соседние кнопки не мешают листать.
- Руку можно листать за любой элемент по ширине и по высоте, включая несколько рядов домино в коротком landscape; прокрутка не разыгрывает карту. Сохранены удержание и перенос к цели.
- Общий кубик «Змей и лестниц» находится под полем в портрете и справа в landscape. Оппоненты начинаются сверху. В шашках используется круглый счётчик фигур без лишних подписей.
- UNO хранит ситуации пропущенного объявления отдельно для каждого игрока; обвинения и штрафы разных игроков являются независимыми действиями.

## Совместимость и ограничения

Движок API 1, представление API 2, контейнер пака 1; stateVersion всех пяти игр — 1. Партия привязана к точному packVersion. Старые опубликованные файлы не переписываются; API представления 1 не поддерживается текущим приложением. Отсутствие нужного пака не повод удалять сохранение.

Данные остаются в браузере того же origin. Хост хранит полную сессию; клиент — только свою разрешённую историю. Полный экспорт хоста не передаётся гостям. Очистка данных сайта и перенос на другой origin не являются обновлением сохранений.

После закрытия WebRTC или перезапуска хоста может понадобиться новый Offer/Answer. Автоматической внешней сигнализации, TURN-сервиса, облачного переноса сохранений и миграции хоста нет. Старое наблюдение о сбое PR2/Auto при VPN остаётся задачей диагностики ICE-01; успешный PR3 не доказывает работу любой сети.

Квоты сетевых пауз, игровые часы и штрафы по времени, команды и расширенная сложность ботов — будущие функции, не часть API 0.15. Подробные статусы — [Roadmap](ROADMAP.md).

## Приёмка

Перед выпуском выполняются полный совместный набор проверок, CI окончательных PR, проверка собранной PWA и скачанных релизных файлов по SHA256. Мобильные исправления проверяются в портрете и landscape; результаты прогонов и точные ревизии записываются в release notes/provenance артефактов.

Пользователь подтвердил работу сохранений, загрузки, звука, разных паков и возврата из меню в сетевую игру. Автоматические браузерные проверки дополняют этот результат, но не обещают совместимость со всеми устройствами и сетями.
