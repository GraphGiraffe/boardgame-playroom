# Данные и совместимость · 0.18

| Данные | Владелец |
|---|---|
| Position / RNG / turn / result | Domain/GameModel |
| Полная история и receipts | Session/authority + repository |
| Разрешённый клиентский архив | HistorySync / client history |
| Имя, аватар, тема, скины, масштаб, звук | Локальные profile/appearance/preferences |
| Каталог, установленные точные версии | Library / pack-loader |
| Выбор карты, прокрутка, история UI | ScreenController / Web view state |

Локальные предпочтения не входят в game commands. Изменение формы руки, масштаба или темы не создаёт ход. Редактирование профиля сохраняется явным подтверждением; отмена не записывает черновик.

## Сохранение

Архив указывает точный packVersion. Library пишет librarySummary и Session одной операцией; список читает заголовок, а open выполняет полную проверку. Заголовок не даёт игровых прав. Отсутствующая версия предлагает установить нужный пак; повреждённые/неподдерживаемые данные не удаляются молча.

Сетевое хранение delta-v1 записывает новые события с eventBase/eventTail, header eventCursor и receipt в одной IndexedDB transaction. Восстановление сверяет цепочку курсоров. Web Locks и repository ports отделяют владение данными от UI.

## Переход с 0.17

0.18 исполняет **только engineApi 3**; API 1/2 не имеют legacy runtime. UpgradeService обнаруживает несовместимую библиотеку и предлагает явное полное обновление с предварительным экспортом. Принятие фиксирует accepted-engine-api=3, но не конвертирует старые правила и не удаляет архивы. Старые опубликованные JSON/теги сохраняются неизменными; данные старого API открываются совместимой прежней версией приложения. Точные RC-версии API 3 также не подменяются стабильными версиями автоматически.

## PWA и паковые обновления

Оболочка и каталог публикуются независимо. Каталог проверяет SHA256, engineApi/viewApi/stateVersion; установка атомарна. Активная партия использует закреплённую версию. Offline использует проверенный локальный каталог и паки.

Service Worker проверяет полный shell до предложения «Обновить». Окна подтверждают безопасное состояние меню без активной комнаты; занятое или неответившее окно блокирует активацию. После активации окна перезагружаются, старые shell caches удаляются, IndexedDB остаётся. Не очищать данные сайта ради обновления. Origin сайта сохраняется при deploy.

Экспорт профиля/перехода не должен включать resume credentials. Trusted pack-loader исполняет установленный JS и не является sandbox.
