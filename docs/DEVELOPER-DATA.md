# Данные, сохранения и паки 0.15

[Индекс](DEVELOPER-INDEX.md) · [формат пака](PACK-FORMAT.md) · [сетевой журнал](LAN-01-SESSION-STORE.md)

## Владельцы данных

| Данные | Модуль | Граница |
| --- | --- | --- |
| Локальные партии, история и метаданные библиотеки | app/library.js, core/session.js | Полная локальная Session; точный packVersion |
| Сетевая партия хоста и receipts | app/network-session-store.js | IndexedDB; приватная authority, commit до ACK |
| История клиента | app/network-client-history.js | Только проекции данного viewer; отдельные Session |
| Право возврата | RoomService/ResumeStore в app/multiplayer.js | Приватный room-scoped токен, не публичный профиль |
| Установленные версии | core/packs.js, app/pack-manager.js | Доверенные исходники правил, view и ресурсы |

Очистка site data удаляет локальную историю. Смена origin не переносит IndexedDB/LocalStorage. Обновление PWA должно сохранять origin и данные; новый service-worker cache очищает старые файлы оболочки, а не библиотеку партий.

## Совместимость

Состояние хранит game, packVersion и данные конкретного пака. Для продолжения и повтора выбирается точная версия. Новая установка не переписывает опубликованное содержимое; исчезнувший пак можно установить снова. Старые сохранения без packVersion относятся к 0.1.0 и не конвертируются автоматически.

Приложение 0.15 поддерживает engineApi=1, viewApi=2, контейнер formatVersion=1. View API 1 отклоняется. Наличие старого сохранения не делает старый несовместимый view работоспособным в новой оболочке; используйте соответствующий прежний выпуск приложения/пака.

Предварительный просмотр импортируемого JSON не исполняет код. После подтверждения пак регистрирует одну игру и view; ошибка не должна разрушать существующий каталог. Сборщик и загрузчик проверяют размер, пути, точки входа и ресурсы. Это не sandbox для враждебного JavaScript.

## Архивы и история

Хостовый архив содержит полную Session и приватные права восстановления. Клиентская запись хранит разрешённые кадры и публичные сведения участников; секреты, полный export и receipts хоста туда не копируются. Догрузка проверяет viewer, sessionId, revision и packVersion. Удаление записи через «Мои партии» удаляет архив только на данном устройстве.

Read-only просмотр не отправляет действия. Ползунок обновляет кадр во время input; проигрывание использует общую анимацию. Выделение участников с данного устройства опирается на сохранённое членство/локальный режим, а не совпадение никнейма.

## Поставки

build.py создаёт `playroom.html`, `playroom-all-games.html` при --all-games, PWA при --pwa, архивы исходников и ядра, SHA256SUMS. Пять встроенных паков берутся из явно указанного --packs-dir. Защищённая Pages-обёртка добавляется только в отдельный приватный ZIP; не включается в исходники или публичные assets. [Процедура выпуска](RELEASING.md).
