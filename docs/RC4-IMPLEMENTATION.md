# RC4: утверждённая работа

Цель: приложение 0.16.0-rc.4 и коллекция 0.5.0-preview.3. Источник требований — согласованный план чата PlayRoom dev, включая последние уточнения. Реализация отмечена ниже; результаты проверок и публикации фиксируются отдельно в RC4-VERIFICATION.md.

## Каталог

- [x] Два вида тегов: тип и механика; 1–3 уникальных, минимум один тип. Закрытый реестр движка и копия в паках, проверка сборки/импорта и legacy category.
- [x] Порядок четырёх строк: Все/звезда; состав; тип; механика. Разделители без заголовков. Состав светлый с рамкой, тип темнее, механика светлая; выбранное тёмное/белое.
- [x] Соло/дуэль/три/команды и типы — общие иконки с подсказкой; 2+/3+/4+/6+ и механики — текст. Состав помещается в 320px. Независимые группы AND, повторный клик снимает, Все/звезда сохраняют фильтры.
- [x] Консервативные теги: UNO и Дурак cards/shedding; Рыба cards/combinations; Акулина cards/combinations/shedding; Пексесо cards/memory; Домино pieces; Шашки и крестики board/logic; Морской бой board; Лудо и Змеи board/race; Ятзи dice/combinations.
- [x] Соло без соперников; дуэль строго 2; три строго 3; N+ хотя бы один допустимый состав >=N; teams реальный режим. Пустые резервные теги скрыты.
- [x] Резерв типов/механик и иконок для пасьянсов, головоломок и roadmap; новые игры не входят в RC4.

## Игры

- [x] Морской бой: запрет касаний в обоих вариантах, announceSinking=true по умолчанию; окружение потопленного отдельными auto-marks без расхода хода/статистики.
- [x] Иконки остатка флота по размерам над полем и в карточке. Без объявления чужие остатки и звук потопления скрыты, собственные видны. Бот использует только открытые наблюдения, hunt/target, направление, размеры, несколько целей, seeded random.
- [x] Личная настройка followOpponent=true: своё поле на чужом ходе, противник на своём; ручной override до смены хода, 220ms slide, результат быстрого выстрела до возврата, reduced motion.
- [x] Лудо: 1(default)/2/3 независимых кубика, порядок свободен, можно одну фишку; сохранять пока ещё может появиться ход. Переброс конкретных шестёрок включён по умолчанию, отдельная опция.
- [x] Лудо: startPawn=false; guaranteedExit=true после 3 неудачных наборов при всех незавершённых фишках на базе, в том числе после сбивания. Выбранный кубик выводит фишку, остальные доступны, без подмены/бонуса; сброс счётчика при выходе. Команды/боты/save.
- [x] Акулина: any(default)/next источник, выбор карточкой игрока; крупная закрытая рука в поле сеткой 5:7 без перекрытия, порядок сохранён. Случайная вставка в любой промежуток, остальные карты не сортировать. Публичная пара имеет звук и анимацию, дама пик не имеет особых эффектов.
- [x] Дурак: simple/throw-in(default)/transfer; 36(default)/52/54; joker color(default)/universal только 54; first-out/last-fool(default). Простой традиционный по 5, атаки 1/3/5; частичный отбой; подкидной по 6; перевод до отбивания с проверкой вместимости и правильным добором. 2–6, обмен младшего козыря, завершение после розыгрыша/добора. Старые версии сохранены.
- [x] Ятзи: все колонки 56px, аватарки, sticky labels/header/footer, очки scroll; суммы. Звук только commit score: numeric/chance, special, yatzy, neutral zero; бонус/финал без наложения.
