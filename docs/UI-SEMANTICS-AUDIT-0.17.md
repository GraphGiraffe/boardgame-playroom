# Аудит повторяющихся элементов · 0.17

Скриншоты сняты 14.10.2026 в мобильном Chromium с локальной сборки 0.17.0 и коллекцией 0.6.0. Владелец продукта подтвердил единый знак удаления: корзина во всех местах, включая последний шаг подтверждения. Цвет кнопки зависит от контекста; текст рядом с корзиной уточняет объект удаления. Остальные решения, пока не подтверждённые им, помечены как выбор Codex.

Скриншоты показывают расположение элементов; актуальные значки и состояния нужно сверить с текущей сборкой при приёмке.
