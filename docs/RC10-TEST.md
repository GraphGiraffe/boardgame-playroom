# Playroom 0.15.0-rc.10

## Состав

- Все пять паков переведены на игровые элементы API 2: UNO 0.3.0; domino, durak, checkers, snakes 0.2.0. Источник паков закреплён: `668effe071389d934c0ed7d3f6535c6cab4b286d`.
- Приложение выбирает компоновку и масштаб поля для вертикального/горизонтального телефона, планшета и ПК. Общие позиции навигации, справки, настроек и действий; единый набор SVG.
- Компактная комната, общие карточки партий и экран истории; изоляция прокрутки окон и исправление продолжения комнаты.
- Семь блоков тестов, подблоки и целевой запуск; обязательный полный gate сохранён.

## Живая приёмка перед 0.15.0

1. Загрузить защищённый архив в тот же Cloudflare Pages проект/production origin. Проверить вход по прежнему паролю и запрет прямого доступа к JS без входа.
2. Обновить установленную PWA на двух устройствах. Проверить сохранённые данные; партии старых паков не конвертируются, API 1 не поддерживается.
3. Вертикальный телефон 320/390 px, короткий landscape, планшет/ПК: поле, рука, кнопки и история всех пяти игр доступны, смена ориентации работает.
4. Прокрутка менеджера паков/правил/настроек не двигает фон; история не требует прокрутки всего экрана.
5. Комната хоста/гостя: места, зрители, правила, nickname в настройках, подключение, готовность; история и выход из завершённой партии; продолжение сохранённой комнаты.
6. Сыграть локально и по WebRTC на двух устройствах, пройти результат → лобби → следующую партию, живой slider и восстановление после reload.
