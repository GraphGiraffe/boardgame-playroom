# RC13 — навигация комнаты и порядок игроков

Предварительный выпуск 0.15.0-rc.13. Стабильный 0.15.0 и автоматическая загрузка в Pages не входят в этот выпуск.

## Поведение

- Крестик лобби и Escape закрывают окно, сохраняя исходный экран. Вложенные правила и настройки возвращаются в лобби. Полный выход — отдельная кнопка «Покинуть комнату».
- Продолжение Offline восстанавливает настройки и места в заблокированном лобби текущей партии, в том числе после перезагрузки и для уже активного сохранения. Записи без лобби получают заблокированный контекст из фактической партии.
- Выход сетевой игры в меню снимает только SharedViews. SessionClient, RTC, сохранение истории, authority, боты и блокировка хоста остаются. Игрок в меню считается подключённым, игра продолжается.
- «Вернуться в партию» и продолжение того же сохранения используют существующую сессию с обновлённым снимком. Пропущенные ходы доступны в истории; открытая игра сохраняет прежнюю очередь анимаций. Фоновая новая партия не открывается поверх меню.
- Одновременно действует одна сетевая комната. Другую игру/комнату можно открыть после явного выхода из текущего лобби. Настоящий обрыв связи допускает прежний QR/recovery путь. Перезагрузка вкладки не сохраняет живой RTC.
- Следующий сетевой матч использует отдельную команду rematch. Стрелка назад в шапке возвращает в меню.
- Для зрителя i противники отображаются i+1, …, n−1, 0, …, i−1. Своя карточка остаётся в личной области. Для зрителя/Стола порядок исходный. Строка читается слева направо, столбец сверху вниз. Правила, индексы, цвета и руки не переставляются; UNO reverse меняет направление хода.

## Контракт и версии

`H.seatOrder(count, viewer)` возвращает индексы отображения. `playerContent` остаётся индексирован игровым индексом.

Статус — строка либо `{label, icon?, motion?}`. Обязательный label обеспечивает доступность и текстовый fallback старого renderer. Общие SVG sword, shield, takeCards рисуются движком в размере строки счётчиков. Пак выбирает смысл статуса.

Коллекция 0.4.0-preview.5: UNO 0.4.4, Дурак 0.3.5, Змеи и лестницы 0.3.3. Домино и Шашки прежних версий. Старые сохранения используют точную версию своего пака; формат состояния не меняется.
