# RC20: квадратная зона полноценного поля и дубль в ЗиЛ+

Приложение 0.18.0-rc.20, коллекция 0.7.0-rc.15, канал 0.18-rc.15. Только защищённый preview.

Полноценное поле получает зону своих пропорций: `family: board`, `fieldSizing: fit`, `fieldAspect` (по умолчанию 1). Маленькие столы с картами и явно заданные `content|scroll` сохраняют своё поведение. Зафиксированная сетка партии не меняется при броске, выборе и появлении действий.

ЗиЛ+ размещает кубики и общую пару ±1 в одной постоянной строке. На портретном экране 390×844 поле в углах, как и в ряд, занимает доступную ширину; на коротком экране уменьшается квадрат целиком. Лудо сохраняет полноценную квадратную зону.

Дубль двух исходных кубиков даёт ещё один бросок после выбранного перемещения и возможного автоматического второго перемещения. Поправка ±1 не создаёт и не отменяет дубль; один кубик бонуса не даёт. После финиша бонус не назначается. На полях 64/100 клеток удалены клетки дополнительного броска. Формат состояния не менялся; обновлён точный packVersion, старые версии неизменны.

Проверки выбраны: `case/rc2-presentation-browser,case/pack-models`. Добавлены измерения квадратной зоны в обеих рассадках, использования полной портретной ширины и сохранения размеров после броска; проверки дубля/поправки/одного кубика/автоматического второго перемещения/финиша, воспроизводимости партий шести игроков. Самостоятельная сборка паков и 17 SHA256 прошли. Снимки `tmp_files/rc2-presentation/rc20-*.png`.

Итог локальных проверок: 65/65, без пропусков (18 модельных и 47 браузерных). Снимки ЗиЛ/Лудо 390×844 и ЗиЛ 320×640/844×390 просмотрены.

Каждый принятый бросок имеет отдельную общую анимацию перед результатом/маршрутом, включая повторные броски с теми же значениями; instant пропускает её. Reduced motion использует короткое появление без вращения. Проверяются ЗиЛ+/Простой/Лудо/Ятзи на всех скоростях, дубликаты событий и повторный бросок.

Рука по умолчанию — по дуге; сохранённое явное straight остаётся. Финальная проверка включает также `case/game-feedback,case/motion-effects,case/network-feedback-browser` для общей очереди и сетевого отображения. Предыдущий результат 65/65 относится к состоянию до этих дополнительных правок.

Дополнительно: исправлены локальный основной игрок/хотсит и сетевые короны (корона вместо player; host + grid для Стола). Стол сохраняет иконку в лобби и отображается последним в карточке сетевой партии на главном экране. Крупные ходы/реплики ниже модальных окон. Итоговый выбранный прогон: `case/rc2-presentation-browser,case/pack-models,case/game-feedback,case/motion-effects,case/network-feedback-browser,case/views,case/lobby-layout-browser,case/network-main-app`.
