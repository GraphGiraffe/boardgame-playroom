# RC20: полноценное поле, броски и роли участников

Приложение 0.18.0-rc.20, коллекция 0.7.0-rc.15, каталог 0.18-rc.15. Опубликованы неизменяемые prerelease-архивы; отдельный Pages preview RC20 не создавался. Итоговый кандидат — RC21.

- Полноценное поле получает зону fieldAspect (по умолчанию квадрат); маленькие столы и явно заданные content/scroll сохраняют своё поведение. ЗиЛ+ и Лудо используют всю доступную портретную ширину при достаточной высоте. ЗиЛ+ размещает кубики и общую пару ±1 в одной постоянной строке. Бросок/выбор не меняет закреплённую сетку партии.
- Дубль двух исходных кубиков в ЗиЛ+ даёт ещё один бросок после всех перемещений. Поправка ±1 не создаёт и не отменяет дубль; один кубик и завершённая партия бонуса не дают. Клетки дополнительного броска удалены с полей 64/100.
- Каждый бросок — отдельный шаг общей очереди до результата/маршрута, включая одинаковые грани; instant отключает его. Лудо передаёт точный набор переброшенных кубиков после смены игрока. RC21 дополняет распознавание совмещённого события roll при reduced motion.
- Карточная рука по умолчанию по дуге, сохранённый straight остаётся.
- В локальной партии основной игрок определяется сохранённым владельцем и местом (включая пересадку): player; добавленные люди — hotseat; корон нет. В сети у хоста только корона вместо player, обычный Стол — grid, хост-Стол — host + grid. Стол сохраняет иконку в лобби и идёт последним после игровых мест в карточке сетевой партии.
- Крупные ходы и реплики находятся ниже окон приложения. Справка комнаты доступна из заголовка настроек.
