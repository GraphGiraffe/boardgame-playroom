# RC17 — ЗиЛ+ и накопленные исправления

Новый режим «ЗиЛ+» выбран по умолчанию. «Простой» сохраняет бросок одного кубика без особых клеток; размер поля 64/100 выбирается отдельно. ЗиЛ+ предлагает два кубика, готовые маршруты и автоматический выбор единственной фишки.

- ±1 — отложенный добровольный выбор поправки следующего выбранного кубика, включая 0. Допустимое итоговое значение 1–6. Эффект расходуется после следующего броска; повтор не суммируется.
- −Кубик — один кубик вместо двух при следующем броске. Пропуск автоматически отменяет следующий ход, сохраняя другие отложенные эффекты.
- Щит автоматически блокирует одну змею, пропуск или потерю кубика. Добровольное −1 не блокируется.
- Второй кубик после попадания на особую клетку срабатывает автоматически, один раз за ход. Каждый выбранный/автоматический кубик показан крупно перед своим перемещением. Между перемещениями фишка и счётчик остаются в промежуточной позиции.
- Дополнительный ход даёт новый бросок. Особые клетки и отложенные эффекты на карточке игрока используют одинаковые векторные значки. Щит не накапливается.

Состояние Змей — версия 2, опубликованные старые паки не изменены. Новые правила детерминированы, команды публичны, бот выбирает доступный маршрут; replay проверяется на обеих досках и трёх режимах завершения с шестью игроками.

Кубики Ятзи, Лудо и Змей всегда показывают грань: отдельный preview RNG для первого отображения не меняет последовательность игровых бросков, затем сохраняется последний результат. Единая палитра слотов/аватаров/фишек не повторяется для поддержанного числа участников. Змеи снова приглушённые, лестницы желтее, тонкий белый векторный контур отделяет их от клеток.

Накопленные исправления предыдущих RC входят в этот кандидат: общие всплывающие справки; модальный выбор карт; настройки без неприменимых/единственных вариантов; свайп карт и домино; компактные руки; адаптивный каталог; скрытие локальной партии только с главной; поддержка шести игроков; очередность от первого игрока и круговая рассадка; рубашки при передаче и крупный показ публичных сетов; колонка имён/карт сетов в Рыбе; оптимизированные runtime-арты с сохранёнными исходниками. Подробности — RC15 и RC16.

Выбранные проверки: `case/rc2-presentation-browser,case/pack-models,case/game-feedback,case/motion-effects,case/motion-settings`. Геометрия нового режима дополнительно проверена и снимки просмотрены на 320×640, 390×844, 640×320, 844×390. Исправлена обрезка ±1 на коротком landscape. Итог выбранного набора: 92/92, skipped 0. Самостоятельная сборка паков: 72 JS, 17 SHA256-файлов, без ошибок. Публикация фиксируется после проверки deployment.

Выпущенная пара: приложение 0.18.0-rc.17, коллекция 0.7.0-rc.13, каталог 0.18-rc.13. Только preview; production не переключается.
