# PlayRoom «ХОД» — v0.15.0-rc.9

Pre-release для проверки на реальных устройствах. После успешной физической приёмки RC9 планируется стабильный 0.15.0; адаптация защищённого Cloudflare Pages-деплоя относится к 0.16.0.

## Исправления

- **RC8-UX-01:** результат клиента удаляется вместе с прежним игровым mount при возврате в лобби. Кнопки закрытия, истории и возврата работают; следующая партия использует живое прежнее RTC и прежнее место.
- **RC8-UX-02:** разрешённый кадр истории отображается во время движения ползунка, до отпускания пальца/мыши. Сам range и фокус сохраняются. Запоздавшие ответы и ошибки отбрасываются; отпускание выбирает точную финальную позицию. Просмотр read-only, без игровых команд, live-звуков и чужих карт.
- При восстановлении закреплённых исходников для сборки декодируется сериализованный ресурс UNO в оригинальные WAV-байты: прежняя сборочная цепочка несколько раз упаковывала data URL. SHA-256 оригинального ресурса проверен; правила, представления, метаданные и номера паков не меняются.

## Автоматическая приёмка

- Реальные два Chromium-браузера по WebRTC: finish → result → lobby; закрытие результата, история, инициатива гостя/хоста, готовность и последующие матчи на том же объекте RTCPeerConnection.
- Непрерывный touch 320 px и mouse 390 px, короткий landscape 740×390 с read-only архивом: поле меняется при удерживаемом pointer, range/focus сохраняются, старые кадры и чужой viewer не отображаются, просмотр молчит и не меняет authority revision.
- Локальная история, host recovery, приватность и общий набор всех пяти игр.
- Отдельный прогон готового автономного HTML и PWA после распаковки, проверка архивов и контрольных сумм перед публикацией.

Локальный полный прогон RC9 с закреплёнными паками: **469/469**. PR [#31](https://github.com/GraphGiraffe/boardgame-playroom/pull/31) и [#32](https://github.com/GraphGiraffe/boardgame-playroom/pull/32) прошли Application checks и Multiplayer preview smoke на своих точных head SHA. Дополнительный [PR #34](https://github.com/GraphGiraffe/boardgame-playroom/pull/34) переводит regression сохранения после reload на стабильный HTTP origin; все проверки приватности и состояния сохранены. Исходная попытка выпускного CI остановилась на этом тесте; RC9 публикуется только после нового полного успешного прогона. PR #34 прошёл обе проверки CI; повторный локальный полный прогон — 469/469. Закреплённая интегрированная база: `55e4ed0536d6bc185176bd09ff9da59ac5753e93`. Точный выпускной SHA, результат повторного полного набора и ссылка на выпускной CI добавляются в GitHub Release. Автоматическая проверка не заменяет Android/Firefox/Safari и реальную сеть.

## Что проверить на двух устройствах

1. Обновить обе установленные PWA до RC9 на прежнем origin, сохранив текущую защиту Cloudflare. Убедиться, что существующие сохранения доступны.
2. Соединить хоста и гостя прежним рабочим PR3-путём; доиграть партию до результата.
3. У гостя нажать «Закрыть», снова открыть результат, «Посмотреть историю», вернуться к результату. Кнопки доступны.
4. Гость нажимает «Вернуться в комнату»: окно исчезает, появляется ожидание хоста. Хост возвращает комнату в лобби; оба подтверждают готовность и играют снова без нового QR.
5. Во второй партии хост возвращается в лобби, пока у гостя открыт результат: окно гостя должно исчезнуть автоматически. Повторить запуск следующей игры.
6. В истории медленно и быстро вести палец/мышь в обе стороны, удерживая: поле обновляется сразу, ползунок не обрывает жест, после отпускания показывает последний выбранный кадр.
7. Проверить архив в «Моих партиях», локальную историю, 320/390 px и горизонтальный экран, закрытые руки и отсутствие звуков при просмотре.
