# Мини-карты: номинал / масть — подготовка общего скина

> Обновление: реализация добавлена в рабочую ветку. Ниже сохранено исходное исследование; действующий объём, отличия от XP и скины описаны в [реализации](SOLITAIRE-IMPLEMENTATION.md). Публикации пока нет.

Статус: согласованное направление, проверено в offline-макетах Паука и Косынки. Канонический набор ассетов и подключение к приложению пока не реализованы и не опубликованы.

## Набор и выбор

- Выделить отдельный `playroom-asset-pack` в коллекции: предлагаемый ID `mini-split-deck`, первая версия `0.1.0`. Существующий `mini-cards` с одним номиналом сохранить без замены.
- Использовать как дополнительный скин семейства `card-face`, видимое название «Мини: номинал / масть». Существующий выбор «Лица карт» в оформлении тем должен показывать доступный вариант из каталога; не заводить отдельное хранилище предпочтений внутри игр.
- Выбор меняет только изображение обычных игральных карт, не состав колоды, правила, instance ID, масть, номинал или сохранённое состояние партии. UNO и специальные лица других игр автоматически этим скином не заменяются.
- Настройка локальна для устройства. Предпросмотр использует draft темы; отмена не меняет применённый скин. Применение — существующей кнопкой сохранения темы. Рубашка выбирается отдельно.
- Набор переиспользуется Пауком, Косынкой и другими совместимыми карточными играми. Подключение через shared assets/compiler, без копий renderer в игровых паках; самостоятельная упаковка и offline включение по действующему контракту asset packs.

## Лицо карты и геометрия

Пропорции 5:7. В верхней половине крупный номинал по центру, в нижней — крупная масть по центру. Сохранить материал, боковую грань, скругление, палитру и доступную подпись общей карты. Номинал и масть одинаково окрашены в цвет масти; символ остаётся различимым без опоры только на цвет. Поддержать все обычные номиналы, включая 10 и локализованные буквы фигур. Джокеры не добавляют карты в игры: для колод с ними отдельно определить два различимых лица перед включением скина в такие колоды.

Размеры карт одинаковы в обоих пасьянсах при одинаковом экране и режиме. По умолчанию компактный режим под десять столбцов Паука; семь столбцов Косынки центрируются без растягивания. Размер не меняется при раздаче, подсказке или росте стопки. Крупный режим остаётся явным выбором.

При перекрытии открытых карт оставить видимой верхнюю половину с номиналом. Нижняя масть перекрытой карты может быть скрыта: до реализации нужно определить доступный просмотр/увеличение, особенно для определения одномастной серии Паука и домов Косынки. Видимые действия не обводятся постоянно: только конкретные объекты запрошенной подсказки; keyboard focus сохраняется независимо.

## Перед подключением

Создать канонический renderer/styles и manifest отдельного набора, зарегистрировать скин в каталоге, проверить применение существующим resolver без подмены специальных лиц. Выбрать минимальные проверки renderer, theme draft/save/cancel, offline упаковки и конкретных карточных экранов. Проверить все номиналы и масти на минимальном размере, увеличение перекрытой карты, контраст и неизменность геометрии при смене скина. Не менять опубликованные версии ассетов задним числом.
