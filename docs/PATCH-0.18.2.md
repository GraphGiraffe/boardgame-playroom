# Патч 0.18.2: сворачиваемые фильтры библиотеки

Состав приложения 0.18.2; факт публикации подтверждается GitHub Release и production report. База приложения 0.18.1, companion 0.7.1; правила, сохранения и версии паков не меняются.

- По умолчанию скрыты три группы: состав игроков, типы игр, механики.
- После «Все» и «Избранное» — кнопка «Фильтры» с локальной SVG-воронкой из общего набора UI.
- Повторное нажатие сворачивает группы. Активные значения и результаты сохраняются при сворачивании и смене «Все»/«Избранное».
- Раскрытие сохраняется при перерисовках текущей страницы и сбрасывается после перезагрузки.
- Кнопка поддерживает Enter/Space, aria-expanded/aria-controls, видимый focus и touch target 44px.

Выбранные проверки: `node scripts/codex/test.cjs case/library-filters-browser,case/rc2-hub-browser`.
Новый малый сценарий проверяет 320/390 portrait, 740×390 landscape и desktop 1280×800; прежний сценарий проверяет фильтрацию, избранное и порядок игр.
Скриншоты до/после — `tmp_files/patch-0.18.2/library-filters` в рабочем корне BoardGames.

Результат: **5/5**, без пропусков; скриншоты закрытого/раскрытого состояния проверены визуально. Полный набор игр/сети не запускался.
