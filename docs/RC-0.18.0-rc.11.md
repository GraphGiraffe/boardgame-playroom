# 0.18.0-rc.11 — необязательная дуга руки

Настройки → «Карты в моей руке» → «По прямой» / «По дуге». По умолчанию прямая; выбор сохраняется локально и общий для карточных игр. Домино не меняется.

Дуга вычисляется по положению карты относительно центра видимой руки и обновляется при прокрутке. Наклон и вертикальное смещение независимы от transform выделения/перетаскивания. Форма руки не меняет размеры карт, карточек игроков и области руки. Наклон и подъём ограничены существующим запасом; размеры рассчитываются по исходным, не повёрнутым элементам, чтобы избежать обратной связи измерений.

Приложение 0.18.0-rc.11; неизменённая коллекция 0.7.0-rc.8, канал 0.18-rc.8. Только preview.

Проверки: case/rc2-presentation-browser,case/game-screen,case/uno-drag,case/motion-effects,case/drag,case/checkers-drag. Новые сценарии: сохранение настройки, обе ориентации телефона/планшета и ПК, все четыре карточные игры, наклон при прокрутке, focus, mouse/touch drag, длинная рука и неизменность домино. Веб-аудит дополнен дугой для всех допустимых составов карточных игр.

Общий расчёт poseOf используется полётом карты и drag-preview: исходные пропорции сохраняются при вытягивании, самостоятельный CSS rotate учитывается один раз.

Результаты проверок и адрес фиксируются после публикации.

Локальная матрица: 1440 состояний, 0 ошибок геометрии/страницы; 34 записи относятся только к длинным рукам (20 прямых, 14 дуговых). Обычные руки без прокрутки. Равенство размеров проверено на 390×844, 844×390, 640×320, 768×1024, 1024×768, 1920×1080.

Выбранные исходные проверки: **110/110**, exit 0. Сборка PWA, standalone и source ZIP прошла. Снимки: `tmp_files/rc11-arc/index.html`.
