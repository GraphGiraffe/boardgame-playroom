# Распространение и тестовые сборки

Приложение и игры распространяются через [сайт](https://graphgiraffe.github.io/playroom-hod-test/). GitHub Releases в репозиториях приложения и паков не используются.

[Локальные сборки](TESTING.md) предназначены для проверки на компьютере и подготовки статических файлов для GitHub Pages или Cloudflare Pages. Публикация и её настройки принадлежат [репозиторию сайта](https://github.com/GraphGiraffe/playroom-hod-test).

Версии приложения, коллекции и паков независимы. Уже опубликованные файлы паков не перезаписываются: сохранённым партиям нужны точные версии. Изменения форматов требуют явного контракта совместимости.
