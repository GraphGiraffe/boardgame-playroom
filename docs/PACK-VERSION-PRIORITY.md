# Приоритет версий паков

Область применения: приложение **0.21.0** и коллекция **0.8.10**, engineApi 4 / viewApi 3 / protocol 3. Исторические этапы ниже поясняют совместимость; текущая приёмка хранится в [utils](https://github.com/GraphGiraffe/boardgame-playroom-utils/blob/main/docs/project/app/reports/ACCEPTANCE-0.21.0.md).

При автоматическом выборе пака для новой партии сначала сравниваются числа
`major.minor.patch`. Суффикс имеет приоритет только при одинаковой основной
версии: `0.6.3-preview.6` выше `0.6.3`, но ниже `0.6.4` и `0.6.5`.

Суффикс не ограничен именем: `sizes`, `assets`, `animations`, `rc` и другие
обрабатываются одинаково. Между суффиксами одной основной версии действует
порядок SemVer, включая числовое сравнение (`sizes.10` выше `sizes.2`).
Метаданные после `+` сами по себе не дают приоритета.

Сохранённая партия продолжает использовать точную записанную версию пака.
Автоматический выбор не мигрирует её правила или состояние.
