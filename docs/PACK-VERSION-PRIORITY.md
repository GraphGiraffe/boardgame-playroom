# Приоритет версий паков

При автоматическом выборе пака для новой партии версии вида
`major.minor.patch-suffix` имеют приоритет над версиями без суффикса.
Это правило приложения, намеренно отличающееся от стандартного SemVer:
любая версия с суффиксом имеет приоритет даже над более высоким номером
обычной версии. Например, `0.5.2-assets.1` выше `0.6.0`.

Суффикс не ограничен именем: `sizes`, `assets`, `animations`, `rc` и другие
обрабатываются одинаково. Внутри каждой группы сохраняется порядок SemVer,
включая числовое сравнение частей суффикса (`sizes.10` выше `sizes.2`).
Метаданные после `+` сами по себе не дают приоритета.

Сохранённая партия продолжает использовать точную записанную версию пака.
Автоматический выбор не мигрирует её правила или состояние.
