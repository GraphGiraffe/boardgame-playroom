# RC14 — взаимодействия, окна и повтор партии

Кандидат 0.15.0-rc.14. Stable 0.15.0 и загрузка в Cloudflare в этот этап не входят.

## Изменения

- Общая структура окна: непрокручиваемая шапка и `.modal-body`. Игровые анимации ниже затемнения. Лобби обновляет DOM по идентификаторам мест, сохраняя фокус, ввод и привязку прокрутки к видимому месту.
- Сетевой экран повторно вычисляет разрешённый ввод после закрытия внешнего окна; SessionClient уведомляет подписчиков после снятия ожидания квитанции даже при уже принятой ревизии.
- Клиентский архив сохраняет идентификаторы участников: собственный ник выделяется по идентичности. В старых записях без идентификатора участник не угадывается по имени.
- Настройки используют общий экран. Переключатель комнаты: «Локальная / Сетевая». Общий компонент карточки продолжения используется для обеих партий, с отдельным полным выходом и переподключением для сети.
- Хост может сохранить и остановить матч, вернув комнату в лобби без разрыва RTC. Сохранённая партия остаётся playing/paused, без победителя. Пауза записывается до перехода; ошибка записи оставляет игру на месте.
- Завершённые результаты закрываются каждым участником самостоятельно. Пока комната в лобби, разрешённая конкретному клиенту история завершённого матча остаётся доступной.
- История показывает компактные руки с прежними правилами приватности. Кубик Змей находится в общей области сцены и виден в повторе и на Столе.
- Звуковой экземпляр ggwave с номером 0 корректно запускается и освобождается. Подготовка запускается одним нажатием; закрытие окна отменяет незавершённый запуск.
- UNO 0.4.5 учитывает штрафы по цели обвинения. Повторы по той же цели в одном эпизоде нейтральны, другие цели независимы. Обычный ход по-прежнему закрывает прежнее окно пропущенного объявления, согласно правилам пака.

## Контракты

`PlayroomGameScreen.modalContent`, `updateModal` и `resumeCard` — общие компоненты приложения. `SessionAuthority.stopForLobby()` — только локальная возможность хоста, не команда сетевого зрителя. Долговременные квитанции такого управления имеют `viewer: -1`, `control: true`, `host: true`; остальные права зрителя не расширены. Старые квитанции продолжают приниматься.

Приватный Pages ZIP собирается через `scripts/package-pages.py --public ... --protected-base ... --output ...`. Скрипт снимает оболочку каталога публичного PWA, проверяет обязательные корневые файлы и сохраняет парольный Worker без вывода секретов. Приватный ZIP не добавляется в Git и публичные assets.

## Проверка

Обязательный gate: `bash scripts/codex/check.sh --full --packs-dir ../playroom-paks/packs`.
Проверяется готовый архив, а не только исходники. Физическая приёмка звука между телефонами и обновления Android PWA отмечается отдельно от браузерных проверок.

## Кандидат и проверенные артефакты

Исходники паков закреплены за `9e20a1d` (коллекция 0.4.0-preview.6). Публичные артефакты и защищённый ZIP — раздельные файлы. Деплой на Pages и стабильный релиз этой задачей не выполняются.

Готовый защищённый ZIP содержит 60 файлов относительно корня. Проверены CRC, байтовое совпадение защитного Worker/маршрутов с предыдущим защищённым выпуском, запрет выдачи страницы/скриптов/Worker без авторизации, а также сетевой сценарий двух браузеров на распакованном ZIP. Последний тест проверяет ресурсы приложения через локальный HTTP; он не эмулирует весь Cloudflare edge.

Звуковые проверки используют настоящую ggwave Wasm и управляемый Web Audio: первый вызов передачи/приёма, допустимый handle 0, повтор после ошибки загрузки и отмена подготовки. Передача через реальные динамики и микрофоны телефонов, обновление установленной Android PWA и вырезы экрана требуют физической приёмки.
