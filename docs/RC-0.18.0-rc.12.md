# 0.18.0-rc.12 — общая компоновка и игровые метки

План: исправить общие руки, размещение участников и меню; затем роли и правила паков; проверить реальные экраны; выпустить неизменяемые prerelease и preview. Production не переключается.

Реализовано: симметричный веер с увеличенным шагом небольших рук, выбор колонок по измеренному переполнению, расширение боковых зон для небольшого поля, компактный выбор карты, видимые якоря речи, меню действий без ограничения высотой карточки. Номера мест 1–8 в углу панели, общий нижний бейдж аватара, одинаковые счётчики флота, простые иконки меча/щита/мешочка. Названия и контракт — [UI-ELEMENTS](UI-ELEMENTS.md).

Настройки: полноэкранный режим и справка в заголовке; быстрые действия слева, темы справа; компактные отступы. Вход в комнату рядом с фильтрами. Остановка комнаты — кнопка без подписи в нижнем ряду. Значения по умолчанию: прямая рука, последняя игра скрыта, звук включён/громко, автоматическая передача и ход одним нажатием включены, средняя анимация. Явно сохранённые настройки не заменяются.

Паки: UNO 0.5.0-rc.7 (до шести игроков); Дурак 0.5.0-rc.7 (меч только у инициатора атаки); Пексесо 0.2.0-rc.6 (Персонажи/Игральные и фиксированный состав). Коллекция 0.7.0-rc.9, канал 0.18-rc.9. Существующие числовые варианты Пексесо читаются; новые настройки предлагают две колоды. Формат состояния не меняется, старые опубликованные версии сохраняются.

Проверки включают восемь размеров 320×640…1920×1080, максимальные составы всех игр, 1/2/3/4/6 карт веера, straight/arc без изменения размеров, приватность проекций, touch/mouse drag, реакции UNO и правила изменённых паков. Общий выбранный прогон: 170/170. После правки перекрытия рук — 43/43; общая правая граница настроек и однострочный заголовок на 320 px проверены отдельно. Полный локальный аудит: 1536 состояний и 108 анимационных сценариев без ошибок. Повторный аудит последней геометрии: 1536 состояний, 0 ошибок, 14 случаев прокрутки только длинной собственной руки; прокрутки миниатюр нет. Публикация добавляется после проверки preview.

Последние уточнения: правая граница заголовка, темы, полей и переключателей единая, включая scrollbar gutter. На узких экранах заголовок меньше и не переносится. Прямая и дуговая руки и руки оппонентов сохраняют перекрытие, не растягиваясь на всю строку.
