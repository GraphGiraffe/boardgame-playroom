# Патч 0.18.1 / коллекция 0.7.1

Состав релиза 0.18.1 / 0.7.1. Факт публикации подтверждают GitHub Releases и production report, не этот документ. База обеих веток `fix/rules-settings-0.18.1` — синхронизированные dev после стабильного выпуска 0.18.0/0.7.0.

## Поведение

- Редактор правил использует метаданные пака: смысловые блоки, два дискретных слайдера в строке; колоды остаются списками, единственные варианты скрыты.
- Пексесо: количество пар 8/12/18. UNO: карт на руке 5/7, объявление Вручную/Авто. Домино: костей на руке 5/7. Шашки: шашек у игрока 8/12. Режимы Лудо, Змей и Морского боя сохраняют существующие правила.
- Рыба: колоды 36/52. Акулина: 35/51 в интерфейсе, исходные ID 36/52. Domain не теряет чтение старых состояний 54 карт; существующие exact-version партии не конвертируются.
- Завершение отделено и перенесено вниз; лимиты раундов 3/5/10/20/50/∞, безлимитный ID остаётся строкой `0`.
- Персональные слайдеры «Отображение руки» (Прямо/Веером) и «Рассадка» в одной строке. Старые значения `straight`/`arc`, `anchors`/`row` сохранены. Неприменимые параметры скрыты.
- Всплывающие справки «?» у параметров, доступные по нажатию; общий блок «О настройках» и отдельная подпись о локальности удалены.
- Правила меняются только после сохранения; закрытие, выбор на шкале и справка не меняют принятую конфигурацию комнаты.

Коллекция обновляет 11 изменённых игр на patch; Крестики-нолики остаются 0.2.0, shared assets и engineApi/viewApi/stateVersion не меняются. app package/PWA cache — 0.18.1, коллекция — 0.7.1.
