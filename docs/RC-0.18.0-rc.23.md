# RC23: общие мини-карточки и одинаковая форма аватаров

Приложение 0.18.0-rc.23, коллекция 0.7.0-rc.17, изолированный каталог 0.18-rc.17. Включены исправления RC22: подтверждение Ятзи, чистый крупный показ пар и сетов. Production остаётся 0.17.6 / 0.6.5.

Мини-карточки номиналов выделены в самостоятельный asset-пак mini-cards 0.1.0: рендерер, CSS, доступные подписи и якоря. Геометрия 5:7, ширина 24 px, торец 1 px, мягкая тень. Номинал слева сверху; шаг перекрытия 14 px одинаков для всех, «10» немного сдвинуто влево. Компилятор обоих репозиториев встраивает scripts и styles набора offline; отдельный ZIP входит в выпуск коллекции.

Спроси рыбу 0.2.0-rc.9: только рассадка в ряд; один или два столбца таблицы по доступной области поля, без порога числа игроков. Аватары и карты по 24 px; сеты в одной строке с внутренней прокруткой. Максимум проверяется искусственно: 6 игроков × 13 сетов, 320×640, 390×844 и 844×390, включая начало и конец прокрутки. Поле и таблица не меняют размеры при заполнении.

Мини-руки во всех карточках игроков, паках, рассадках и поверхностях всегда обрезаются по высоте; полная геометрия карт и домино сохранена. Собственная рука и модальный выбор остаются полными. У всех аватаров квадратная форма и единое скругление 22% стороны; фиксированные радиусы отдельных контекстов удалены. Изображения сохраняют пропорции и одинаковые внутренние отступы. Проверяются лобби, настройки, выбор аватара, игровая карточка, таблица Рыбы, сохранения и результаты в обеих ориентациях телефона.

Выбранный gate: `case/rc2-presentation-browser,case/network-feedback-browser,case/model-contract,core/packs,case/game-screen,ui/appearance`. Итог: **117/117**, без пропусков (core 48, presentation 56, network 10, appearance 3). Первый широкий прогон дал 114 pass / 3 fail из-за устаревшего пути к темам; актуализирована навигация теста через настройки → редактор → Применить, все прежние проверки отмены, контраста, состояния и сохранения окна остались. Адресный повтор ui/appearance прошёл 3/3. Самостоятельная проверка паков прошла: синтаксис, сборка, 18 SHA256. Все остальные 11 игровых JSON побайтно совпали с опубликованной коллекцией RC16; старые версии не переписаны. Политика CI не изменялась, проверки защиты веток API недоступны (HTTP 403).

Ограничение прежней расширенной матрицы game-layout-browser сохранено: до этой правки уже были ошибки ожиданий дубликата своего игрока, компактных кнопок, границ повёрнутых счётчиков и отдельных низких экранов. Базовый RC22 в изолированном checkout дал 115 pass / 65 fail; рабочий срез до RC23 — 186 pass / 59 fail вместе с presentation/network. Эта матрица не выбрана новым выпускным gate и не объявляется пройденной; ослабление её порогов ранее отклонила автоматическая проверка, пороги не изменены. Внесено только различение обрезки overflow:hidden и настоящей вертикальной прокрутки согласно принятому требованию пользователя. Подробности — FISH-TABLE-REVIEW.md.

Публикация: новые immutable GitHub prereleases, скачанные SHA256/ZIP CRC, отдельный каталог и защищённый Pages preview; точные SHA/URL/отчёт проверки добавляются после публикации. Стабильный основной адрес не переключается.
