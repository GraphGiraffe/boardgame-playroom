## Контракты

Пак может предоставить `reactionWindows(state)` — массив уникальных дескрипторов `id/owner/revision/humanMs/botMs/fallbackMs`, не больше числа игроков. Старый `reactionWindow(state)` адаптируется в массив. Authority хранит таймеры и подтверждения показа по ID каждого окна; snapshot содержит `reactionWindows` и совместимое `reactionWindow` владельца либо первое доступное окно.

`reactionControl(...).independent: true` разрешает обработать реакцию при устаревшей общей ревизии только когда цель и эпизод всё ещё соответствуют текущему действию пака. Проверка прав, правил, session/epoch и дедупликация commandId сохраняются. Это не разрешение выполнять устаревшие обычные ходы.

Общий элемент сцены `elements.shared` предназначен для единственного публичного интерактивного объекта. Его геометрия принадлежит приложению; правила и внешний вид объекта остаются в паке.

`stopForLobby()` объединяет параллельные запросы, запрещает новые команды, дожидается текущей записи и сохраняет паузу до выхода в лобби. Ошибка записи оставляет комнату в игре. Локальная остановка сохраняет playing-сессию без назначения победителя.

## Границы проверки

Обязательная команда: `bash scripts/codex/check.sh --full --packs-dir ../playroom-paks/packs`.

Снимок пользователя с английскими режимами не совпадает с RC14 исходниками и проверенным защищённым архивом. При проверке обновления архивов воспроизведено смешивание новой страницы со скриптами RC14 из старого кэша; оно устранено адресацией ресурсов по содержимому. Причина именно на устройстве пользователя не установлена; нельзя считать кэш или ошибочный деплой доказанными. Проверка обновления в браузере не заменяет приёмку установленной Android PWA. Акустическую передачу между реальными телефонами также проверяет пользователь.

Приватный Pages ZIP собирается из окончательной публичной сборки и прежнего защитного Worker через `scripts/package-pages.py`. Worker, маршруты и приватный архив не добавляются в Git или публичные release assets. Старые партии требуют точной версии пака, поэтому прежние опубликованные архивы не заменяются.

Исходники паков: `4d20252f112f9c49e8eb7c678f5c3472074a42d8` (0.4.0-preview.7).

## Результаты RC15

Полный совместный прогон: **739/739**, без пропусков и отмен (ядро 70, ввод 82, игры 328, экраны 126, сохранения 34, сеть 58, подключение/PWA 41). Самостоятельная проверка паков: синтаксис, сборка и семь контрольных сумм — успешно.

Проверен защищённый ZIP из 108 корневых/вложенных публичных и защитных файлов. На одном origin выполнен переход с фактического RC14 ZIP: HTML вместо скрипта отклонён при установке; исправное обновление ждёт закрытия вкладки; локальная партия сохранена; после открытия загружается UNO 0.4.6 и доступна остановка. На этом же распакованном ZIP сетевой сценарий двух браузеров завершён успешно (1/1).

Скриншоты после обновления и остановки сохранены вместе с локальным отчётом кандидата. Проверка не публикует Worker и не заменяет работу Cloudflare edge или испытание физического телефона.
