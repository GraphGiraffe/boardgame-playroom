# RC24: общая иконка карт без неоднозначного номинала

Приложение 0.18.0-rc.24. Коллекция 0.7.0-rc.17, канал 0.18-rc.17 и все pack JSON остаются прежними. Включены изменения RC23; production не переключается.

Согласованная общая иконка: две карточки, верхняя наклонена вправо, нижняя вертикальна. Семёрка заменена уголком-бликом только на верхней карте. Единые stroke-width=2, круглые окончания и соединения, currentColor и viewBox 24×24 сохранены. У задней карты один видимый контур вместо нескольких наложенных линий. Все потребители (фильтры, кнопки, игровые реплики с отдельным количеством) используют TabletopUI.icon('cards'); правок только для Рыбы нет. Номиналы настоящих карт и числовые счётчики не меняются.

Выбранный gate: `case/game-screen,case/game-feedback` — **22/22**, без пропусков (19 screen, 3 feedback); дополнительно визуальный просмотр общей иконки в меню и реплике «передал 1 карту» на телефоне в обеих ориентациях. Правила, сохранения, API и сеть не менялись; полный набор не запускается для этой локальной правки SVG. Известные ограничения старой матрицы компоновок остаются описаны в RC23 и не объявляются исправленными.

Публикация: immutable prerelease приложения с точной парой SHA, проверка скачанных архивов и SHA256/ZIP CRC, один protected preview на прежнем каталоге RC17. Итоговые результаты, SHA и URL дополняются после проверки.

Просмотрены `tmp_files/cards-icon-review/rc24-hub-{390,844}.png` и `rc24-transfer-{390,844}.png`; в сообщении отдельная цифра 1 не смешивается с номиналом иконки. Согласованный SVG не содержит номинала.
