# RC16 — очередность, круговая рассадка и публичные сеты

- Номер очередности отсчитывается от первого игрока, а не индекса участника. Публичный orderPosition пака имеет приоритет; смена направления UNO не перенумеровывает игроков.
- Угловая рассадка распределяет соседние места последовательно по периметру, с обратным вертикальным порядком западных групп. Идентификаторы игроков и руки не переставляются.
- Общая рамка действия кубика повторяет скругление грани. Змеи красные, лестницы насыщенно-охристые, заметнее на обеих клетках поля.
- Передача закрытых карт использует рубашку даже в играх без колоды-источника.
- Публичный сброс пары/сета использует общий reveal cards: вход, читаемая пауза, полёт к месту сброса. Все карты видны; закрытые передачи не получают публичных лиц. Новая карта сброса скрыта до завершения показа.
- Спроси рыбу: все имена в общем столбце, маленькие карты сетов справа с общей начальной координатой. Лицо сета — первая карта в порядке руки, сохранённая в bookCards. Новая версия состояния пака 2; старые партии закреплены за прежним паком.

Пара кандидатов: приложение 0.18.0-rc.16, коллекция 0.7.0-rc.12, изолированный каталог 0.18-rc.12. Production не переключается.
