# Изменения

## В работе — единый игровой цикл для local / hot seat / WebRTC

- Один `GameFlow` задаёт `instant/fast/normal/slow`, reduced motion, `quickPlay` и применение движка `PlayroomMotion` без локальной/сетевой развилки. Сетевые действия анимируются при новых подтверждённых ревизиях; дубликаты, повторы истории и первые снимки ничего не повторяют.
- Сетевая настройка «Ход одним нажатием» теперь берётся из того же профиля приложения. Переключения обновляют текущую сцену без пересоздания игровых правил.
- У большой карточной руки сохранено перекрытие и при горизонтальной прокрутке; тонкие боковые отметки показывают невидимые за краем карты. Адаптивный ввод, миниатюры и reduced motion проверяются отдельными регрессиями.
- Исправлены пропорции временного выделения игрока и кнопки UNO. Игровая логика и версии паков не меняются.
- Это изменение не составляет новый стабильный релиз; физическая приёмка Android/iOS необходима.

## Unreleased — универсальные игровые события и действия на сетевом экране

- Переиспользуемый `PlayroomPlayerTarget` для двухэтапного выбора игрока: красное выделение токена и руки, кнопка над рукой, подтверждение вторым тапом, отмена через 2 секунды. Только разрешённые действия, без сетевой отправки при первом тапе.
- `PlayroomGameFeedback`: заметные сообщения из разрешённых событий пака, сетевые звуки через общий `TabletopAudio`, защита от повторов и звуков при просмотре истории.
- Общий финальный экран (`GameScreen.resultMarkup`) для локальных режимов и WebRTC: победа/поражение, очки, публичный Стол и история.
- Новые JS/CSS-ресурсы включены в автономную сборку и PWA; версия UNO 0.2.1 описывает новый способ обвинения и метки UNO без изменения игровых штрафов. Опубликованные паки 0.2.0 и релиз preview.3 остаются неизменными.
- Добавлены unit и browser regressions для корректного/ложного выкрика, обвинения, двухтапового выбора, звуковой дедупликации, финала и приватности.

## Unreleased — единый игровой экран в сетевой партии

- Сетевой игрок использует тот же `GameScreen` и `combined`-представление пака, что и локальная игра с ботами/hot seat; отдельная упрощённая оболочка и её стили больше не используются.
- Восстановлены руки и статусы соперников (только разрешённые проекцией), привычные иконки управления и встроенная панель истории с предыдущим/следующим действием, ползунком, воспроизведением и возвратом к текущей партии.
- Команды и просмотр истории остаются за SessionClient и правами текущего места. Сетевой Стол остаётся публичным и не получает чужих скрытых карт. Все локальные сохранения, паковые API и опубликованная `v0.15.0-preview.3` остаются без изменения.
- Регрессионные проверки: общая разметка GameScreen, реальная отрисовка приватной проекции, UI двух браузеров и одних origin, история и доступность рук противников.
- Этот раздел описывает кандидат для проверки; новая стабильная версия или Pre-release ещё не опубликованы.

## 0.15.0-preview.3 — 2026-10-08

- Сообщение о недоступной старой версии пака удаляется после удаления проблемного сохранения; менеджер паков проверяет актуальные ссылки сохранённых партий.
- Подключение из другой вкладки того же браузера создаёт отдельного участника. Сетевой вход не принимает общий ID браузерного профиля как полномочие места/хоста.
- Правила комнаты видны строками с названиями настроек и читаемыми вариантами из пака (например, «Объявление UNO: Вручную · можно ошибаться») вместо внутренних значений `manual`.
- Регрессионные проверки покрывают независимые ID участников, подписи правил и UI приглашения.
- PWA/WebRTC и ручной pairing из preview.2 сохранены. Восстановление сетевой партии после перезапуска вкладки ещё не реализовано.


## 0.15.0-preview.2 — 2026-10-07

- Добавлена installable PWA-сборка: manifest, Service Worker и offline app-shell.
- Pairing можно передавать через Web Share; установленный ХОД регистрируется как Web Share Target.
- Добавлен custom protocol handler `web+playroom:` для открытия pairing-ссылок напрямую в PWA.
- Offer/answer получили `pairingId`; ответ от старого приглашения отвергается до WebRTC negotiation.
- SDP скрыт из основного UX; copy/paste сохранён только как fallback.
- Исправлен перенос длинных сетевых уведомлений/toast на мобильных экранах.
- PWA-функции требуют HTTPS (или localhost для разработки); Web Share/Share Target/protocol handlers используются только при наличии поддержки браузером.


## 0.15.0-preview.1 — 2026-10-07

- Первый минимально тестируемый browser-to-browser multiplayer: основной Playroom на двух устройствах, WebRTC DataChannel, ручной offer/answer pairing, лобби, цветные места, ready и 3-секундный старт.
- Имя игрока при первом запуске, название комнаты, зрители, kick и уведомление при изменении правил.
- Удалён отдельный Node/HTTP LAN-host preview; хост теперь обычная вкладка основного приложения.
- На этом preview reconnect и локальный архив сетевой истории ещё не входят в приёмку.
